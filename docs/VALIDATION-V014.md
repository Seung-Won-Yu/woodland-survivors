# 0.14 — 병기 조합·보스 공략·야전 격납고

2026-11-05 · `operation-0.14.0`.

## 구현 범위

두 대원·세 전선의 순환은 유지하면서 기본 무기 3→5종, 최종 합체 1→3종, 연구 5→8종, 최초 지령 3→5개로 확장했다. 로비·전장 환경·보급/성장 선택·HUD·연구·병영·결과 화면을 같은 군사 아케이드 방향으로 교체했다. 신규 별도 작전이나 대원은 추가하지 않았다.

| 기본 병기 | 운용 | 최종 합체 |
|---|---|---|
| P 권총 | 길게 관통하는 집중 사격 | P+S → 레일 브리처: 긴 레일과 근접 산탄 동시 발사 |
| H 기관총 | 지속 연사·도탄·충전 | H+R → 미사일 호위 기관포: 연사 적중이 유도탄 발동 |
| R 로켓 | 넓은 폭발·점화·전도 표식 | H 또는 F와 합체 |
| S 샷건 | 짧은 사거리·근접 산탄·장갑 파쇄 | P와 합체 |
| F 화염방사기 | 짧은 화염 부채·지속 화상 | F+R → 네이팜 스웜: 화염 부채·추적 소이탄 |

합체는 두 기본 무기 3단계+핵심 1개다. 재료를 한 칸으로 합치고 각 연구 개조를 계승한다. 합체에 쓰인 기본 무기를 같은 완성 병기의 새 재료로 다시 제시하지 않는다. 비워진 지원 슬롯으로 다른 총을 추가해 연구 조합을 만들 수 있다.

첫 보급은 현재 총의 합체 파트너와 시드로 뽑은 다른 총을 함께 제시한다. 가득 찬 슬롯의 보급은 새 총 선택 후 **주무기 교체 / 지원무기 교체 / 취소**를 별도로 고른다. 현재 무장을 정비하는 선택도 남겨 원하지 않는 합체·교체를 강요하지 않는다. 이후 보급의 새 총 후보는 회전하므로 다른 합체 경로로 전환할 수 있다.

## 연구가 두 총 사이에서 만드는 변화

기존 5종은 유지하며 세 연구를 추가했다.

| 연구 | 영구 해금 조건 / 가격 | 이번 판 장착 효과 |
|---|---|---|
| S 플레셰트 | S 누적 150처치 / 220C | 산탄 +2, 근거리 보스 부위 피해 +25%. P+S에 계승 |
| F 촉매 연료 | F 누적 150처치 / 260C | 화상 중인 대상에게 산탄·폭발 피해 +35%. 다른 총과 F+R에도 적용 |
| R 전도 탄두 | R 누적 300처치 / 300C | 폭발 표식 2.5초, 표식 대상에 P/H/S 탄환 피해 +25% |

표시되는 교차 효과는 도탄 전력망(H 도탄+축전), 열압 반응(F 촉매+S/R), 전도 파쇄(R 전도+P/H/S)다. 피해/충전은 실제 적중·상태에 따라 계산한다. 소이 지대도 화상 상태를 남긴다. 합체 연구 호환성은 재료 태그로 판정하며 H/R·P/S·F/R의 처치 진척을 각각 남긴다.

P+S와 F+R 각각으로 작전을 완주하면 새로운 실증 지령이 최초 180C를 지급한다. 발견한 합체는 격납고에 표시한다. 과거 H+R 해금·처치·재화·훈련은 보존하며, 기존 H+R 합체 진척은 새 수집 기록에도 반영한다.

## 보스별 공략 계약

| 보스 | 행동으로 얻는 이득 | 공격·표현 |
|---|---|---|
| 장갑 수송차 | 돌진을 유도하고 옆으로 피한 뒤 후방 원뿔에서 엔진 사격. 정측면은 후면 보너스 없음 | 돌진 경로 예고, 돌진 후 3초 엔진 노출. 후면 ×2.8, 정면·측면은 낮은 피해 |
| 철도 포격대 | 좌우 포대 제거로 해당 방향 위험 차선을 없애고 본체 방어를 단계적으로 약화 | 이동하는 청록 안전 통로와 붉은 포격 차선. 포대 0/1/2 파괴 시 본체 배율 .08/.4/1.35 |
| 지휘전차 | 포탑·궤도 장갑을 깨고 노출 코어에 폭발 화력 집중 | 포탑은 회전 레이저, 궤도 장갑은 박격포를 유지. 두 부위 파괴 뒤 3.6초 코어 노출과 짧은 재장전 반복 |

항구 코어는 닫힌 상태에서 본체 피해를 받지 않는다. 마지막 부위 파괴가 즉시 공격 창을 연다. 강해진 빌드의 마무리를 HP 증가로 늦추지 않았다. 통신 교란 보급은 철도 포격을 실제 1개 차선, 최종 보스 박격포를 실제 1발로 줄인다.

보스 명칭·공략 문장·부위 상태·잠긴/열린 코어·후면 엔진 위치·안전 통로·레이저 예고를 별도로 표시한다. 보스 물리 필드나 차선 좌표가 손상된 저장은 재개하지 않고 확보 성과 복구 정산으로 보낸다.

## 전체 화면 방향

- **로비:** 정비 중인 Slug와 석양 항구가 보이는 실제 격납고 배경. 왼쪽 작전 설명, 오른쪽 대원/출전 무장과 합체 경로. 모바일 출격·이어하기는 하단 고정.
- **전장:** 모래·굽은 흙길·야자수 해안, 복선 철로·화물/컨테이너 야드, 콘크리트·크레인·조명탑 항구. 기존 캐릭터 유지.
- **보급:** 베이지 문서 대신 리벳·경고 줄무늬·금속 탄약 상자. 무기 실루엣, 강화 전/후, 교체 손실, 합체 경로, 선택 키를 표시.
- **HUD/기지:** 남색 금속·황동/주황 강조, 큰 아케이드 숫자, 무장 아이콘과 합체 준비도. 연구·병영·훈련·결과에도 같은 토큰 사용.
- **접근:** 키보드 1/2/3와 리롤·교체 취소 유지, 장식 숫자는 접근성 이름에서 제외. 긴 모바일 선택/결과는 상단부터 안전하게 스크롤.

## 검증

자동 검사와 입력 주행의 최종 수치는 아래 결과 JSON과 함께 기록한다. 사람이 느끼는 재미·장기 유지율과는 구분한다. 모델 정책은 현재 상태로 위험과 목적지를 정확히 계산하므로 사람보다 유리하다.

`npm test` **224/224 통과**, 그중 작전 규칙 **58/58**. `npm run build` 통과, `npm run test:pages` **4/4** 통과. 새 합체의 연구 계승/태그/저장, S 사거리와 지속 화상, 교차 연구 피해, 교체 취소, 보스 측면/후면·포대별 방어·잠긴 코어·안전 통로·통신 교란, 이전 경제·수집 기록 보존을 포함한다.

입력 주행은 HP·무기·시간 주입 없이 이동/회피/스킬/선택/상호작용을 사용한다. 선택창과 일시정지를 제외한 전투 시간이다.

| 목표 합체 | 마르코 중앙 시간 / 최종 보스 | 피오 중앙 시간 / 최종 보스 | 실제 조립·완주 |

- 기본 경로 8판: **8/8 승리, 오류 0**, 220.5~301.0초. Slug 경로 4회 포함. [결과](design/mission-pilot-v014.json).
- 합체 목표 12판: **12/12 의도한 합체로 승리, 오류 0**, 220.5~308.3초. 진화 상태 처치 2861~3706. [결과](design/mission-builds-v014.json).
- 연구 여정 5판: **5/5 승리, 오류 0**. P+S → F+R → H+R → F+R+S → P+S로 전투·실제 정산·연구 구매를 이어 총 8종을 구매. 후반 F+R+S 판에서 열압 반응과 전도 파쇄가 함께 활성화됐다. 무기/재화를 직접 주입하지 않았다. [여정과 구매 내역](design/mission-research-journey-v014.json).

초기 계정도 빠른 조립으로 4분보다 짧게 완주할 수 있다. 완료 시간이나 캐릭터별 같은 난이도를 강제하지 않으며, 사람의 실제 선택 고민과 유지율을 이 수치로 단정하지 않는다.

PNG 검수: 환경 시트 **1254×1254 RGBA, 16/16 셀 비어 있지 않음, alpha 0~255**. 격납고 **1672×941 RGB**. PNG 바이너리·CSS 배경과 모듈 버전이 저장소 하위 경로에서 정상 제공된다.

실제 인앱 브라우저에서는 이전 작전 성과 정산·기존 연구 보존, 새 격납고, 신규 해안 배경, 보급에서 S 획득, P 분열 개조와 S 병행 전투, P+S 조합 준비 표시를 확인했다. 데스크톱과 390×844·320×640에서 상자 UI·스크롤·출격바·무장 HUD를 검사했다. 무기 교체 취소·완성 합체·보스별 약점·연구 교차 피해는 규칙 검사와 입력 주행으로 검증한다.

수동 브라우저에서 세 보스를 연속 완주하는 검증, 물리 휴대전화 두 손 멀티터치와 저사양 장시간 성능은 남아 있다. 초기에 보인 셀별 소품 원화와 실제 작은 화면의 가독성은 동일하지 않으므로 실기기 플레이가 추가로 필요하다. 배경 소품은 물리 장애물이 아니다.
