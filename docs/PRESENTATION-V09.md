# 0.9 표현·상호작용 구현 기준

2026-11-05 · [기획](GAME-DESIGN.md)의 화면 계약. 신규 원화나 외부 UI 라이브러리 없이 기존 그림·음향·Canvas를 사용한다.

| 순간 | 화면/전투 표현 | 다음 행동 |
| --- | --- | --- |
| 출전 | 대원 원화 옆에 역할·레벨 성장·E 충전 행동·약점. 위쪽에 두 구역+군주 여정 | 무기와 대원을 고르고 출전 |
| 구역 진입 | 보급로는 흙길/밝은 풀, 심부는 이끼/군락, 최종전은 열린 원형 공터. 짧은 지역 이름 표시 | 새 무기/보스 표식을 따라 이동 |
| 전투 HUD | HP·XP·E, 현재 구역/목표, 격화 예고. 별도 숙련 게이지 없음 | 캐릭터와 경고를 보며 이동·방어 |
| 보급 | 무기 역할/공격 형태→현재 빌드 연결→차지할 슬롯. 보류 가능 | 새 공격 획득 |
| 레벨업 | 보유 공격의 이번 변화와 단계, 다음 진화 조건. Lv.10만 스타일 선택 | 투자 또는 스타일 확정 |
| 진화/합체 | 큰 무기 이름·소모→결과·핵심 역할. 준비/부족 조건을 글자로 표시 | 같은 정비 패널에서 실행/보류 |
| Pip | 짧은 목재 충격, 산탄은 넓은 호박색 파편, 왕복 핵심은 좁은 청록 궤적 | 군집과 단일 표적에 다른 조준 |
| Bram | 실제 전방 호를 가드 용량으로 채움. 소진에 파열, 재정비는 빈 호 | 막을 방향과 빠질 시점 선택 |
| 보스 | 위험 면→배우/아군 효과→위험 외곽선→HP/표적 순. 군주의 지원 꽃은 독립 HP/꽃잎/치유 연결선 | 회피·주 표적·지원 표적 선택 |
| 격파/출구 | 기록·인장 즉시 저장, 정비 패널 하나. 복귀 후 문 모양 출구와 목적지 표시 | 더 사냥하거나 실제 출구로 이동 |
| 결과 | 성공/실패·도달 구역→완성 빌드→새 기록/도전→다음 목표 하나 | 대원/스타일/조건 난도를 바꿔 재도전 |

글자 역할은 제목/핵심 본문/수치/보조 정보를 구분한다. 390px에서 핵심 조건은 12px 이상, 주요 터치 행동은 44px 이상으로 확인한다. 일시정지의 재개/종료는 스크롤과 무관하게 접근 가능해야 한다. 화면 흔들림·적중 정지는 짧게 제한하고 적대 경고는 아군 이펙트 위에 남긴다.

실제 desktop/mobile와 키보드·터치, 긴 레시피 이름, 보급 보류/재방문, 종료 취소, 보스 후 전이, 합체 직후 전투를 검증한다. 고정 검수실은 일반 원정 완주 증거와 분리한다.
