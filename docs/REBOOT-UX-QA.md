# 재기획 화면 흐름·예외·수용 기준

2026-11-06 · 시제품 일부 구현 / 확장 명세 · [규칙](REBOOT-RULES.md) · [콘텐츠](REBOOT-COMBAT.md)

현재 구현 범위·실제 조작 검증·남은 차이는 [첫 시제품 기록](REBOOT-PROTOTYPE.md)을 따른다. 이 문서 전체를 구현 완료로 해석하지 않는다.

## 1. 플레이어가 보게 될 순서

| 화면 | 읽고 결정할 것 | 입력·다음 상태 |
| --- | --- | --- |
| 로비 | 대원 행동, 다음 도전 하나, 새 후보 | 출격→저장 성공 후 전투. 시제품은 연구/지갑을 숨김 |
| 첫 보급 | `H 강화 / R 확보 / 도탄기` 같은 현재 선택 | 1–3/터치. 분화·교체는 같은 패널에서 전후를 확인 |
| XP 성장 | 지금 투자되는 대상·변화, 재추첨/제외 잔량 | 확정 후 전투. LV6는 운용 토글도 함께 확정 |
| 선택 무기고 | 현재 3후보, 상자 희귀도, 습격의 대가 | 카드 선택=확보 / ‘상자를 걸고 습격’=시작 확인 |
| 습격 확인 | 잃는 현재 상자, 보급차/장갑 계약의 HP·호위·경로·보상 표 | 시작 전 취소 가능. 선택 계약 저장 성공 뒤 전투 |
| 습격 중 | 수송차 HP/탈출 진행·포격 예고 | 이동·사격·회피. 일시정지에서 철수 가능 |
| 습격 결과 | 성공 새 후보 / 실패 상자 손실 | 성공 모듈 선택 후 전투. 실패 짧은 안내 후 전투 |
| 장비/조립 | 가능한 진화·합체·조율, 소비·유지·빈칸 | G/장비. 조립 전후 확인, 취소는 비용 없음 |
| 보스 진입 | 한 문장 공략·지금 무장, 별도 성장 문턱 없음 | F/상황 버튼으로 도전, 취소해 필드 유지 |
| 보스 클리어 | 출구·조율권/회복(중간1개/HP15, 시제품·최종0), 다음 준비 | 진행/잔류. 추가 무기 투자 카드는 없음 |
| 출구 | 현재 확보 성과·열린 다음 구역/귀환·진행 중 도전 포기 | 도전 중 떠날 경우 미완 보상만 잃는 것을 표시 |
| 결과 | 결과·새 기록·빌드 핵심 효과·다음 목표 | 같은 대원 새 시드 / 로비 준비. 수당 상세는 펼치기 |
| 저장 실패 | 확정되지 않은 구매/보상·마지막 저장 시점 | 재시도. 성공 전 새 결과·새 지갑을 보여주지 않음 |

## 2. 카드와 위험 선택의 정보량

성장 카드는 `대상·한 가지 변화·지금 연계·비용` 순서다. 용어만 나열하지 않는다.

```text
H / L3 → L4
유탄 급탄
8번 발사마다 유탄 1발
연소 표적에 폭발: 촉매 연료와 연계
[이번 레벨 투자]  [선택]
```

두 분화가 있으면 카드 안에서 두 작동 방식을 고르고 ‘선택’으로 확정한다. 같은 총 두 분화를 별도 카드 두 장으로 늘려 다른 투자 자리를 없애지 않는다. 자세한 수치는 펼쳐 보되 발동 간격·소비·불이익은 숨기지 않는다.

```text
현재 상자: 희귀 / 축전 코일 2강화 등 3후보
[이 보급 확보]        [상자를 걸고 습격]

보급차 성공: 일반70% / 희귀27% / 원형품3%
장갑 계약 성공: 일반40% / 희귀45% / 원형품15%
원형품: 미보유 불안정 과급기 확정 후보
수송차를 탈출선 전에 격파
실패·철수: 지금 상자 소실 / 기존 무장·확보 수당 유지
```

습격 성공 확률을 70% 같은 숫자로 표시하지 않는다. 70/27/3과40/45/15는 각 계약을 **성공했을 때 보상 품질** 확률이다. 실제 성공은 이동·화력·회피로 결정한다. 설계용 기대값의 가정 성공률을 게임 UI에 사실처럼 쓰지 않는다.

조립 화면은 소비할 두 총과 결과의 주공격·페이로드를 연결해 보여준다. `H 연사 유지 + R 추적 폭발 계승`, `조율권1 소비 / 모듈 유지 / 무기 한 칸 확보`를 확정 버튼 주변에 함께 표시한다.

## 3. HUD·모바일·입력

전투 중 중요한 정보는 HP/전술기, 주목표, 공격3·모듈4, 현재 경계/도전, 점수다. 통계 상세·전체 조건은 장비/지도에서 읽는다.

| 영역 | 데스크톱 | 390×844 모바일 기준 |
| --- | --- | --- |
| 상단 좌측 | 대원 HP·차체·충전 | 폭 약156 안에서 HP·충전, 추가 설명은 접음 |
| 상단 우측 | 점수·시간·정지 | 폭 약130, 정지는 독립 터치 영역 |
| 상단 중앙/목표 | 짧은 주목표·경계 예고 | 긴 문장은 두 줄 이내. 전투 중 튜토리얼 모달 반복 금지 |
| 하단 장비 | 총3·모듈4 아이콘, 조립 가능 | 왼손 스틱 **위**의 장비 줄. 스틱 영역과 겹치지 않음 |
| 조작 | WASD/회피Space/전술E/상호F/장비G | 왼손 스틱, 오른손 전술·회피·상황 버튼. 터치 목표48px 이상 |

보스전은 선택 거점 안내를 접고 보스 부위·공략 상태를 보여준다. 카메라가 대원과 활성 위험을 함께 담아야 하며, 화면 밖 경고는 방향을 표시한다. 막히지 않은 출구와 수송차 탈출선을 미니맵에도 구분한다. 기본 공세는 `경계`, 도전은 `도전 D1`, 도박은 `증폭 습격`으로 이름을 나누고 P 같은 내부 변수를 노출하지 않는다.

모달 진입 때 이동/회피/전술 입력을 해제한다. 이전에 누르고 있던 키·터치는 새 선택을 확정하지 않는다. 첫 카드로 포커스를 옮기되 단축키는 **새로 눌렀을 때만** 반응한다. Esc는 원래 선택을 보존한 정지 화면, 재개는 그 선택으로 돌아온다. 숨겨진 배경 탭은 정지하며 복귀 후 자동 진행하지 않는다.

폰트 확대·긴 모듈명·숫자 네 자리·대체 언어에서도 카드와 버튼이 겹치지 않아야 한다. 희귀도는 색+등급명+기호로 표현한다. 저장 오류는 화면읽기 알림을 제공하고 오류 상태에서도 키보드 포커스가 사라지지 않는다.

## 4. 첫 시제품의 세 판 실험

| 판 | 패/검증 질문 | 관찰할 실제 행동 |
| --- | --- | --- |
| A | H 집중·도탄 단일 진화. 희귀품 없이 완성이 즐거운가 | 군집을 연결하는 이동, 보스 약점 유지, 조율권 소비 이유 |
| B | R/축전 또는 F/촉매를 얻고 시작 계획을 바꾸는가 | 투자 분배·유탄/화염 연계·사건 접근 방향의 변화 |
| C | 좋은/나쁜 현재 상자와 낮은/높은 HP에서 습격을 고르는가 | 확보/습격 이유, 실패 후 회복 경로, 다음 판 재도전 의사와 행동 |

시드를 사람이 원하는 결과로 맞춰 놓고 자연 발생 다양성이라고 설명하지 않는다. 먼저 공개된 비교 시드로 작동을 확인하고, 별도 무작위 20시드의 제시·최종 장비 분포를 수집한다. 같은 우선순위 정책의 반복과 패 적응 정책의 결과를 분리한다. 사람에게 특정 빌드를 만들라고 지시한 판과 자유 선택 판도 구분한다.

첫 세 판은 작은 정성 실험이다. 실제 사용자에게 플레이를 맡겨야 자발적 선택·재출격을 관찰할 수 있다. 자동 조종기 완주나 개발자의 시연으로 사용자 재미를 통과 처리하지 않는다.

## 6. 개발 착수와 확장의 문턱

**착수 가능:** D01–D12와 Q01–Q19를 구현자가 같은 뜻으로 설명할 수 있고, 설계 계산의 투자·수당·확률 합계가 일치할 때. 이 문서의 체크리스트가 통과한 제품이라고 주장하지 않는다.

**첫 시제품 확장 가능:** 정상 입력 20시드에서 무효/막힌 성장 0개, 희귀품 없는 완성 경로 작동, 3개 전투 비교 장면에서 경로별 장단점, 사람 자유 선택 세 판의 다른 판단을 확인했을 때. 같은 완성·동선이 70% 이상이면 원인을 검토한다. 같은 효과를 다른 이름으로 낸 결과는 다양성으로 세지 않는다.

**공개 기본 주소 교체 가능:** 두 대원·전체 구역·정산·연구·재출격·이관과 Q01–Q19의 해당 범위를 실제 브라우저에서 검증하고, 사람 플레이의 미해결 실패를 기록했을 때. 그 전에는 기존 배포본을 보관하고 독립 시제품으로 검증한다.

수치 조정마다 전면 개발을 뒤집지 않도록 피해·주기·확률·XP·생성·수당·가격을 데이터로 둔다. 반대로 슬롯/자원/합체 계승/승리·저장 계약을 몰래 수정해 테스트만 통과시키지 않는다. 구조 수정이 필요하면 실제 실패 장면과 바뀌는 선택을 먼저 기록한다.
