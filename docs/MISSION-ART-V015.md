# 0.15 차량 분리 레이어

[차량 원화](../public/art/mission/vehicle-layers-v015.png) · [최종 프롬프트·도구 기록](../public/art/mission/provenance-v015.json)

- 모드: 내장 `imagegen`. 기존 `vehicles.png`를 질감·팔레트 참고로 사용해 새 아틀라스를 생성했다.
- 프로젝트 경로: `public/art/mission/vehicle-layers-v015.png`.
- 원본 도구 출력: `exec-807a82a8-a542-4930-bcae-58937c15a702.png`.
- 1254×1254 RGBA, 2×2. 왼쪽은 차체, 오른쪽은 포탑. 윗줄은 은색 Slug, 아랫줄은 올리브·적색 적 전차.
- 이전 고정 옆모습을 모든 이동 방향에 쓰는 대신, 회전 가능한 정사영 레이어를 사용한다. 코드에서 장착 축을 정렬하고 차체·포탑·반동·궤도를 따로 그린다. 원본 PNG의 투명도를 유지했다.
- 생성 결과와 실제 렌더를 확인했다. 기존 대원·적·격납고·환경 원화는 유지한다. 기존 차량 아틀라스도 차고의 미탑승 차량·물자 등에서 사용한다.
