# 0.12 작전 아트 제작 기록

2026-11-05에 built-in imagegen으로 투명 PNG 세 장을 생성했다. 기존 게임에서 추출한 스프라이트는 사용하지 않았다. 마르코·피오는 메탈슬러그 캐릭터에 기반한 팬 시제품용 표현이다.

| 경로 | 제작 내용 | 사용 |
|---|---|---|
| `public/art/mission/operators.png` | 마르코·피오 동/북 방향 4프레임 걷기, 4×4 | 전투·기지 초상 |
| `public/art/mission/enemies.png` | 보병·방패병·박격포병·장교 4프레임, 4×4 | 전투 |
| `public/art/mission/vehicles.png` | Slug·지휘전차 4상태와 구출·보급·엄폐물, 4×4 | 전장·보스 |

각 원본은 1254×1254 RGBA다. 생성 결과를 원본 크기로 유지하며, 렌더러가 정수 셀 경계와 내부 여백을 사용한다. 서쪽은 동쪽 프레임 반전이다. 완전한 8방향 원화는 아니다. 반동·발광·잔해·폭발·경고 장판은 Canvas 코드로 합성한다. 배경은 Canvas로 도로·진지·장애물·색조를 그린다.

모든 셀의 알파 영역과 크기를 검사했고 실제 게임에서 대원과 적, 사물의 배치를 확인했다. 최초 생성 결과를 채택했으며 이후 이미지 편집은 하지 않았다.

정확한 최종 프롬프트, 도구, 날짜와 원본 파일 식별자는 [provenance.json](../public/art/mission/provenance.json)에 보존했다. 세 PNG가 최종 납품 자산이며 빌드에 포함된다. 생성 기록 JSON은 소스 관리용으로만 보관한다.
