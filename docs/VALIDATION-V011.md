# 0.11 시제품 검증 · 2026-11-05

## 범위

`prototype.html`의 다람쥐 2분 전투를 별도 모델로 구현했다. 기존 긴 원정은 보존하고 출전 화면에 시제품 진입 링크를 추가했다. 시제품에 공방·촉매·합체 레시피나 영구 능력치 해금은 넣지 않았다. 이번 목표는 짧은 전투에서 두 성장의 이동 문법과 진화 직후의 대군 처리 변화를 확인하는 것이다.

## 규칙 검사

전체 166개(기존 154 + 시제품 12), 정적 빌드, Pages 경로 검사 4개를 사용한다. 새 검사는 무효/중복 선택, 선택·정지 중 시간 동결, 관통 중복 적중 방지, 이동 기반 씨앗·최소 간격·연쇄 상한, 빠른 보스의 씨앗 선분 충돌, 진화와 1회 회복, 적 상한에서 보스 슬롯 확보, 경고→돌진→빈틈, 보스 막타와 동시 적중 정산, 120초 종료, 구르기, 새 판 초기화를 다룬다.

검수 중 발견한 ‘막타 tick 이후에도 상태가 바뀌어 결과 스냅샷과 처치가 어긋남’은 모든 동시 적중을 정산한 뒤 결과를 확정하도록 수정했다. 배경 복귀 뒤 효과음 재개 누락, 320px에서 스틱/버튼 겹침도 수정했다.

## 입력만 사용한 모델 주행

재현: `node scripts/sprint-pilot.mjs --summary`. 시드 17, 71, 2026. 고정 장비·무적·시간·HP 주입 없이 `chooseSprint`, `sprintAction`, 이동 입력으로 진행한다. 정책은 24방향의 적 밀도를 읽고 보스 돌진을 피하므로 사람보다 정확하다. 아래 수치는 사람 승률이 아니다. [전체 실행 자료](validation-sprint-runs.json).

| 경로 / 진화 | 완주 | 중앙 종료 | 중앙 보스전 | 중앙 처치 |
|---|---:|---:|---:|---:|
| 관통 / 대군 | 3/3 | 98.93초 | 8.92초 | 1,093 |
| 관통 / 보스 | 3/3 | 103.28초 | 13.27초 | 862 |
| 씨앗 / 대군 | 3/3 | 94.67초 | 4.65초 | 1,070 |
| 씨앗 / 보스 | 3/3 | 103.65초 | 13.63초 | 1,083 |

무입력 대조 6회는 전부 50초 진화 이전 사망했다(중앙 관통 23.93초, 씨앗 25.70초). 능동 정책의 잔여 체력은 거의 최대다. 군집 배치·정밀 회피가 가능한 정책과 실제 조작의 간극이 크다. 특히 씨앗 대군 진화는 준비한 덫을 보스에게 겹치면 보스 집중 진화보다 빨리 끝날 수 있다. 진화 간 균형의 합격을 주장하지 않는다.

## 인앱 브라우저

- 데스크톱 1280×720: 시작, 첫 경로 선택, 관통 사격, 50초 진화, 대군 처리, 보스 예고·격파·결과를 실제 키 입력으로 진행. 조정 중 관통 대군으로 1:43 / 533 처치 완주를 확인했다. 이 실행은 최종 증원 밀도 변경 전이다.
- 모바일 크기 390×844: 시작·두 선택·덫 이동/기폭·회피·실패 결과·같은 경로 재도전을 확인. 키 입력으로 진행한 덫 대군 실행은 약 70초 / 554 처치에서 사망했다. 진화 전후 처치 증가와 실제 생존 난도 차이를 확인하고, 씨앗 유지 수·감지 범위·진화 충격파·회복·잡몹 접촉 피해를 조정했다. 최종 튜닝 이후 모바일 크기 덫 완주를 확인한 것으로 적지 않는다.
- 320×740: 카드·텍스트·상단 HUD의 가로 넘침 없음. 활성 스틱 x12–112, 액션 x155–308로 겹치지 않음을 DOM 경계와 화면에서 확인했다.
- 스틱 드래그·고유기 버튼 단일 포인터 반응을 확인했다. 두 손 동시 입력 소유권은 기존 터치 컨트롤러 단위 검사로 확인했으며 실제 휴대전화의 두 손 조작은 미검증이다.
- 브라우저 오류 로그에서 실행 오류가 없음을 확인했다. 실제 출력 사운드의 청취 품질과 저사양 기기의 성능은 별도 검증 대상이다.

## 남은 판단

이 버전은 ‘재미가 검증됐다’는 완성 선언이 아니다. 긴 원정을 다시 확장하기 전, 사용자가 관통과 덫을 한 판씩 직접 골라 보고 **선택이 움직임을 바꾸는지, 진화 후 시원한지, 반대 경로를 다시 하고 싶은지**를 확인할 수 있는 작동하는 시제품이다. 새 경로와 기존 원정 통합은 그 피드백 다음에 판단한다.
