# RIFT 0.17 — 작전실과 UI/UX 검증

2026-11-06 · 전투 규칙 b06-swarms 유지

## 이번 변경

- 기존 격납고 원화와 피오 스프라이트를 사용한 로비. 출격·병기·연구·기록 네 메뉴.
- 실제 세 전선의 브리핑 지도. 지도 선택은 브리핑만 바꾸며 새 판은 해안에서 시작한다. 활성 저장판은 해당 전선에서 이어 한다.
- H/R/F의 분화·단일 진화·전도 합체·열압 연계를 확인하는 병기 자료실. 미구현 무기나 대원은 선택지로 만들지 않는다.
- 연구의 실증 조건·가격·부족 C·소유·첫 실전 대기 상태를 분리한다. 진행 중인 작전이 있으면 연구를 잠근다.
- 성장 카드에 총/모듈 그림, 실제 효과, 투자·슬롯 비용을 표시한다. 재추첨과 후보 제외는 상단에 둔다.
- 결과는 확보 C와 이번 무장, 다음 행동을 우선한다. 같은 시드는 보조 행동이다.
- 저장 복귀와 중도귀환을 분리한다. 종료 전 정산 예정 C와 초기화 항목을 확인한다.
- 새 대화상자는 상단과 제목에 초점을 두며, 하위 선택 취소는 원래 후보로 돌아온다. 저장 중 Escape는 대기하고, 저장 실패 경고의 재시도 경로를 유지한다.
- 손상된 이전 보고서는 삭제하지 않고 목록에서 제외한다. 현재 규칙과 다른 보고서에 첫 완주 보너스를 역산 표시하지 않는다.

## 실제 브라우저 확인

Codex 인앱 브라우저에서 페이지의 실제 버튼·키보드 입력을 사용했다. 게임 상태·저장·적 HP·장비를 주입하지 않았다.

| 화면/동선 | 확인 |
| --- | --- |
| 데스크톱 1280×720 | 출격 지도·대원·주 출격 버튼이 첫 화면에 들어옴 |
| 모바일 393×852 | 로비 주 행동 노출, 세로 성장 카드 3개 비교, 연구·보고서 가독성 |
| 작은 모바일 320×740 | 병기 자료실 가로 넘침 없음 |
| 브리핑 | 항구 브리핑을 눌러도 새 출격은 해안으로 시작 |
| 설정 | 효과음 토글 저장 뒤 같은 창·체크박스 초점 유지. 완료/ESC로 원래 메뉴 복귀 |
| 키보드 | 대화상자 Tab 순환, 후보 제외 취소 시 원래 버튼 복귀 |
| 성장 | 실제 LV2 화면에서 재추첨 수 감소와 상단/제목 초점 확인 |
| 저장 | H L2·LV2·0:05 상태를 로비로 저장한 뒤 새로고침·재개 확인 |
| 종료 | 종료 취소는 판 유지, 확정 후 0C/110점/11처치 보고서. 활성 판 종료 및 기록실에서 다시 열기 |

연구 구매 이후 다시 출격하는 실제 장기 순환은 아래 공개판 검증으로 확인했다. 0.17에서는 기존 공개 프로필의 C·연구·보고서 유지와 새 메뉴를 추가 확인한다.

## 공개판 전투·연구 순환 증거

## 자동 검사와 한계

- 전체 규칙/UI 계약316개 통과. UI 계약은 활성판 재개, 브리핑과 시작 맵 분리, 연구 조건·가격·소유, 보고서 다음 행동·재도전 시드·이전 규칙 보너스, 손상 보고서 제외를 검사한다.
- 정적 빌드 및 Pages 하위 경로4개 통과. 새 interface 모듈·격납고·굵은 한글 폰트도 실제 의존성 검사에 포함한다.
- 독립 코드 검토에서 발견한 비동기 저장/Escape·손상 보고서 문제를 수정하고 재검토했다. 저장 실패의 실제 디스크 장애는 브라우저에 주입하지 않았다.
- 3경로×4시드 모델 완주12/12는 진행 가능성 증거다. 사람이 자발적으로 다음 판을 시작하는 재미의 증거로 해석하지 않는다.
- 공개 완주2:38은 숙련된 자동 입력의 빠른 돌파 사례다. 4–6분 자유 플레이 체감 목표를 충족했다고 단정하지 않는다.
