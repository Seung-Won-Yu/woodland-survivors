# 0.10 · 결전의 빈틈과 합체 화력

0.9의 두 구역 → 최종전 구조와 성장 조건을 유지한다. 이번 수정은 긴 보스전, 수호형 합체의 군집 처리 회귀, 변신의 피드백, 모바일 입력에 집중한다.

## 전투 규칙

| 조정 | 이유와 표현 |
| --- | --- |
| 보스 HP 3,500 / 34,000 / 115,000 | 첫 수문장의 긴 단일 대상 전투와 최종 체력 소모전을 단축 |
| 공격 뒤 1.35초 빈틈 · 무기 피해 +45% | 피한 뒤 몰아치는 행동에 보상. HP바·예고 문구를 금빛으로 표시 |
| 집중 포격은 650 안의 보스 우선 | 가까운 잡몹에 조준이 흡수되던 손실 해결. 280 안의 치유 꽃은 먼저 처리 가능 |
| 수호형 벌떼는 330 안의 표적 분산 | 모든 벌이 같은 적으로 쏠리던 문제 수정. 표적이 죽거나 맞았거나 범위를 벗어날 때 재탐색 |
| 일반 꿀벌 4단계부터 재공격 1회, 60% 피해 | 첫 보스에서 가시·꿀벌 조합의 단일 대상 공백 보완. 진화 후 두 번째 공격은 100% |
| 군락 진입 첫 40초 | 약한 버섯·돌격 전열 중심으로 시작. 초당 7→13.4마리, 첫 공세 65마리. 이후 기존 특수 적·대군으로 전환 |

유물·고유기·특성의 추가 피해에는 보스 빈틈 배율을 붙이지 않는다. 충전과 연계의 출처 구분, 재공격 횟수·수명·관통 예산도 유지한다. 합체의 추가 무기 칸은 그대로 돌려준다. 산개형 왕복 산탄은 군집, 반달 핵심은 단일 대상·귀환에 강한 구분을 유지한다.

## 변신과 타격의 표현

- 조건이 갖춰지면 전장에 **공방 준비** 버튼 표시. 일시정지 외에도 바로 열 수 있다. 가까운 장소가 없으면 F도 공방을 연다.
- 선택 패널 안에서는 피해를 발생시키지 않는다. 전장 복귀 시 실제 무기가 즉시 발사되며, 2.6초 완성 이름과 짧은 각성 고리를 표시한다.
- 진화 무기의 처치 반응은 방향을 따라 더 멀리 흩어지고, 적중 별·처치 저음·합체 발사음을 구분한다. 사운드는 기존 레인 제한을 유지하고 플레이어 피격음을 우선한다.
- 적의 위험 경고는 아군 효과 위에 유지한다. 화면 전체 섬광은 추가하지 않는다. 모션 감소 설정에서는 카메라 흔들림·완성 배너 진입 애니메이션을 줄인다.

## 모바일 입력

- 조이스틱과 각 행동 버튼이 자기 포인터를 소유한다. 다른 손가락이 이동을 빼앗거나 취소하지 않는다.
- 구르기·고유기는 pointerdown에 발동한다. 뒤따르는 click으로 중복 발동하지 않으며 키보드/보조기기 click은 유지한다.
- 중심 7px는 이동 없는 여유 영역. 메뉴·포커스 이탈·회전·리사이즈에서 이동과 눌림/capture를 함께 해제한다.
- 안전영역을 반영하고 일반 세로 화면에서 구르기를 76px, 고유기를 68px 이상으로 배치한다. 320px 폭에서는 HP·시계·지도를 축소하고 단계 띠를 숨긴다. 행동 버튼은 각각 70px·62px 이상을 유지한다.
- 준비/충전 상태는 기존 행동 버튼의 하단 게이지로 표시한다. 새 전투 자원을 추가하지 않는다.

## 기록과 배포

규칙 이름을 `expedition-v10`으로 분리한다. 0.9의 최근 기록과 개인 최고 기록은 보존하고 새 최고 기록과 시간을 섞지 않는다. 이미 얻은 과밀 해금도 유지한다. 진행 중 원정의 복원 UI는 여전히 제공하지 않는다.

정적 배포는 진입점뿐 아니라 모든 모듈 import와 CSS에도 같은 배포 버전을 붙인다. Pages의 파일별 캐시로 서로 다른 전투 코드가 섞이는 것을 방지한다.
