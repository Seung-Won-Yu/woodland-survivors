# 0.14 — 격납고와 세 전선 환경 제작

도구: **built-in imagegen**. 2026-11-05에 신규 생성했으며 CLI/API 대체 경로는 사용하지 않았다. 기존 캐릭터·적·병기는 [0.12 자산](MISSION-ART-V012.md)을 유지했다. UI의 무기 실루엣은 `src/mission/icons.js`의 SVG 코드다.

| 최종 저장 경로 | 용도 |
|---|---|
| `public/art/mission/hangar-v014.png` | 석양 항구를 바라보는 야전 격납고 로비 배경. 인물은 기존 대원 원화를 별도로 배치 |
| `public/art/mission/environment-v014.png` | 4×4 투명 환경 시트: 야자수·벙커·철조망·해안포 / 컨테이너·화물차·탄약 / 크레인·조명탑·드럼·감시탑 / 파괴 흔적·덤불·바리케이드·정비대 |

정확한 최종 프롬프트, 투명 배경 설정과 원본 식별자는 [provenance-v014.json](../public/art/mission/provenance-v014.json)에 보존했다. 생성 결과를 프로젝트로 복사했으며 이미지 편집·축소는 하지 않았다. 로비는 CSS 배경, 환경 시트는 Canvas 알파 경계 crop으로 사용한다. 두 이미지 모두 정적 빌드에 포함된다.

제작 지향은 메탈슬러그에서 착안한 군사 아케이드의 질감이다. 공식 게임에서 추출한 배경·스프라이트는 사용하지 않았다. 격납고는 짙은 남색 철골·황동 조명·주황 석양, 전장은 모래 해안·녹슨 철도·회청색 항구로 분리했다. 탄약 상자 UI의 테두리·리벳·경고 줄무늬·버튼은 CSS로 구현했다.

새 소품은 장식이며 이동을 막는 물리 장애물은 아니다. 카메라 가까이 있는 적·탄환·예고와 UI가 계속 읽히도록 주요 경로와 거점 바로 위는 비워 배치한다.
