# RIFT 0.18 — 전장과 정비 흐름

2026-11-06 · b06-swarms 전투·성장 수치와 저장 포맷 유지

## 문제와 변경

전장은 거대한 점선 원·고정 안내 글씨·동일한 도로가 덮여 있었고, 작전도에는 그 지형이 없었다. 레벨2는 단색 총 아이콘과 `12→14`만 있는 큰 종이 카드였다.

- `field-scene.js`의 지형을 월드·작전도·로비의 큰 작전 지도에서 함께 사용한다. 기존의 가상 해안 지도는 제거했다. 저장된 판은 현재 위치·확보 상태·파괴된 장애물까지 지도에 반영한다. 해안 도로, 철도 선로·분기, 항구 부두·컨테이너 길목을 구분한다.
- 로비에서 정한 출격 시드를 실제 출격에 쓴다. 이미 진행 중인 판은 저장된 시드·지역을 기준으로 한다. 이동 보급차는 출격 후 움직인다.
- 새 작전 시작 저장이 실패해 재시도하더라도 성공한 시점에 다음 출격 계획으로 갱신한다.
- 큰 보급 원과 상시 긴 이름을 제거한다. 감옥·트럭·무기고·레이더 소품, 가까운 지점의 작은 괄호와 짧은 상태 표시를 쓴다. 해킹 범위와 피해 예고는 유지한다.
- 소품·블록·대원을 앞뒤 위치에 따라 그린다. 파괴 가능한 해안 방벽의 네모 외곽 틀을 없앴다. 구출 직후에는 포로가 잠시 나타나고 다음 목표로 넘어간다.
- H/R/F·의료 가방·탄약함·코일 원화를 새로 만들었다. 노획 화면, 하단 무장, 장착 알림에 같은 병기 그림을 쓴다.
- 단순한 초반 레벨업은 짧은 현장 정비 목록, 새 총·모듈은 노획 선택으로 구분한다.
- H L2는 표기 연사 화력+17%, 경계0 해안 일반병 직격3→2발을 설명한다. R의 반경 증가를 사거리로 오표시하지 않으며, 점화 R의 코일2/촉매2 대체 진화 조건도 반영한다.
- HP·충전은 실제 상한 기준으로 표시한다. 슬롯 교체·무료 개장은 추가 선택에서 확인한다. 원래 선택·재추첨·제외·취소·키보드 조작·저장 원자성을 유지한다.

## 실제 브라우저

인앱 브라우저에서 실제 클릭과 이동 키를 사용했다. 장비·적 HP·저장 상태를 주입하지 않았다.

1. LV2에서 H L2 선택 → 하단 H 슬롯과 `연사 화력+17%` 장착 피드백 확인.
2. 경비 제압 → 포로 구출 보상 → F 새 총 선택 → 슬롯 화면 취소/원래 후보 복귀 → 다시 빈 슬롯에 장착 → H L2/F L1 HUD와 전투 재개 확인.
3. 저장한 판을 새로고침·재개한 뒤41C 중도정산. 다음 로비에서 현지 미리보기의 네 지점 좌표를 읽고 새 출격과 대조.
4. 감옥 `(1010,920)`, 무기고 `(1260,510)`, 탄약 `(410,350)` 일치. 이동 보급차는 브리핑 `(510,690)`에서 실제 시작 뒤 `(514.2,690)`으로 이동했다.
5. 다음 판은 R 보급이 제시됨. R 빈 슬롯 장착 → 실제 H L2/R L1 HUD, 구출 포로의 짧은 표시, 새 다음 목표, 장착 알림을 확인했다.
6. 데스크톱1280×720, 모바일393×852에서 정비·노획 후보를 렌더링했다. 모바일 노획 카드 높이199/190/190px, 가로 scrollWidth393px로 넘침이 없었다. 실제 전장 지도 중심으로 바꾼 로비도393×852에서 출격 버튼 하단821px로 첫 화면 안에 들어온다.
7. 로컬 브라우저 오류 로그0건.

## 자동 검증과 범위

전체 규칙·UI326개, 정적 빌드·Pages4개. 새 검사는 모든 H/R/F 레벨 전이, R 분화별 진화, 혼합 보급 상한, 초반 정비 분류, 홀수/짝수 시드 지형, 캐시 재사용/지역 재생성, 소품·대원 앞뒤 순서, 최초 출격 저장 실패·재시도 후 다음 시드를 포함한다. 독립 코드 검토에서 발견한 오표시·시드 소비 문제를 수정했다.

이번 실전 확인은 전장→성장→노획→장착과 저장·다음 출격 연결을 대상으로 했다. 최종 보스까지의 전체 순환은0.16.1 검증 기록을 보존한다. 새 지형과 지도는 데이터·캐시 검사로 검증했으며 이번 UI 수정 뒤 세 보스 전부를 브라우저로 다시 완주했다고 주장하지 않는다.
