# 다람쥐 · 두 갈래 숲길 (0.11)

기존 원화를 유지한 별도 전투 시제품이다. 긴 원정의 장비·공방·이동 절차를 가져오지 않고 **성장 선택이 움직임을 바꾸는지**부터 확인한다. `/prototype.html`에서 바로 실행한다. 기존 원정은 그대로 남긴다.

## 한 판의 계약

- 목표: 전투 시간 2분 안에 큰뿔 수문장 격파. 선택·일시정지 중에는 시간이 흐르지 않는다.
- 0–7초: 이동과 자동 도토리 사격. 첫 무리에서 경험치를 줍는다.
- 7초: 관통 사수 / 씨앗 덫꾼 중 선택. 추가 재료 없이 즉시 작동한다.
- 7–50초: 경험치 회수로 자동 강화. 작은 수치마다 메뉴를 열지 않는다.
- 50초: 선택한 무기를 진화. 넓은 대군 처리 / 보스 집중 중 하나를 고른다. 체력 +40과 주변 충격파으로 강화 효과를 보여준다.
- 50–90초: 사방의 무리와 예고 증원. 적을 쓸어 담는 구간.
- 90초: 수문장. 돌진 경로 예고 → 돌진 → 긴 빈틈을 반복한다. 잡몹은 소수만 보충한다.
- 격파 즉시 결과. 120초까지 못 잡거나 HP가 0이면 실패. 결과에서 같은 조건의 반대 경로로 바로 재도전한다. 영구 능력치 보너스는 없다.

## 서로 다른 이동 문법

| | 관통 사수 | 씨앗 덫꾼 |
|---|---|---|
| 자동 공격 | 이동 방향 근처의 적을 우선 조준. 곧게 이동하면 관통·탄속 강화 | 가까운 적에게 보조 사격. 일정 거리를 움직일 때 발밑 뒤쪽에 씨앗 배치 |
| E / 오른쪽 큰 버튼 | 바라보는 쪽에 넓은 관통 일제. 무리 속에 길을 낸다 | 깔아 둔 씨앗을 차례로 폭발. 자신의 이동 궤적으로 적을 유인한다 |
| Space / 작은 버튼 | 짧은 무적 구르기. 두 경로 공통 | 동일 |
| 대군 진화 | 세 줄 관통 + 다중 적중 파열 | 씨앗 15개·폭발 반경·연쇄 증가 |
| 보스 진화 | 한 줄 집중탄 + 보스 피해 증가 | 수문장 적중 씨앗이 한 번 더 폭발 |

덫은 정지해서 생성할 수 없고, 가까운 같은 자리에 겹쳐 놓을 수 없다. 돌진하는 보스는 이동 선분으로 덫과 충돌 검사한다. 관통탄은 같은 적을 중복 타격하지 않는다. 연쇄 폭발은 유한한 개별 씨앗만 소모한다.

## 표현과 UI

원화 캐릭터·버섯·벌레·수문장·나무를 재사용한다. 전장은 넓은 흙 공터와 가장자리 숲. 적/아군 공격/보스 예고의 색과 층을 구별한다. 타격 순간 밝기·짧은 밀림·사망 잔상·묶음 타격음으로 결과를 전달하고, 화면 흔들림과 플래시는 줄이기 설정을 제공한다.

화면 상단은 HP·남은 시간·처치, 하단은 성장 진행과 경로별 행동 안내. 큰 선택창은 두 번만 등장하며 각 카드가 ‘어떻게 움직일지’를 먼저 설명한다. 모바일은 왼쪽 스틱, 오른쪽 두 버튼; 전투 시야는 모든 화면에서 같은 월드 범위를 포함한다. 결과에는 처치·최대 연속 처치·경로 고유 성과와 최고 기록을 보여준다.

## 판정 기준과 한계

- 15초 이내 두 경로의 다른 행동이 눈에 보여야 한다.
- 진화 직후 적 여러 마리를 한 번에 처치할 수 있어야 한다.
- 보스는 체력만 늘려 시간을 끌지 않고, 예고를 피한 뒤 빈틈에 공격한다.
- 같은 시드의 다른 경로 재도전은 메뉴를 거치지 않는다.
- 모델 검사와 입력 주행은 규칙·종료·처리량을 검증한다. 재미 자체의 합격 판정은 실제 플레이 피드백으로 남긴다.
