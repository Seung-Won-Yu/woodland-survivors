**해석:** 재미의 중심은 ‘강해질 수 있으니 머무르지만, 더 오래 머무를수록 떠나기 어렵다’는 판단이다. 별도 처치 수치만 채우는 것이 목적이 아니다. 캐릭터·아이템이 성장 효율을 바꾸고, 포탈이 그 효율을 다음 위험으로 가져가는 선택이 된다.

우리는 자동 공격·원화풍 2D라는 장점을 유지한다. 3D 점프·지형 이동, 최종전의 무기 압수, 복잡한 상점 규모까지 그대로 옮길 근거는 없다. 특히 완성한 합체 무기를 즐기고 싶다는 사용자 요구와 무기 압수는 충돌하므로 가져오지 않는다.

## 3. Burst: 획득·강화·진화와 모드의 승리 조건을 분리한다

| 단계 | 첨부에서 확인한 내용 | 근거 |
| --- | --- | --- |
| 출전 | 포켓몬마다 시작 기술·패시브·Burst가 다르고, 일부는 진화/폼에 따라 기술과 타입도 바뀐다 | B 2, 3.4–3.5 |
| 새 공격 획득 | 시작 기술을 포함해 최대 3기술. **새 기술은 일반 레벨업이 아니라 기술 습득 아이템으로 선택**한다 | B 3.4, 3.7 |
| 강화 | 일반 레벨업은 최대 세 후보 중 하나. 공통 능력치와 현재 기술의 전용 강화를 선택한다. 기술 습득과 기존 기술 강화는 별개다 | B 3.3–3.4 |

| 큰 행동 | Burst는 포켓몬 고유의 능력이며 충전 시간과 효과 지속 시간은 별개다. 메가진화는 대응 장비·최종 모습 등 추가 조건의 별도 시스템이다 | B 3.4, 7.4 |

### 같은 게임 안에서도 한 판의 목적은 다르다

아래는 **첨부의 10.2.0 설명**이며 현재 10.5의 직접 플레이 검증 결과가 아니다.

| 모드 | 첨부에 적힌 목표 | 우리 설계에 주는 의미 |
| --- | --- | --- |
| 클래식 | 15분 생존과 울트라 보스 처치. 생존 기록과 승리 판정이 다름. 기록을 고정한 뒤 마무리 연출로 종료 | ‘오래 살았다’와 ‘보스를 잡고 이겼다’를 같은 결과로 취급하지 않음 |
| 러시 | 보스 4마리 순서 격파 | 연속 보스 진행은 별도 목표 체계로 설명 가능 |
| 타워 | 방마다 다른 목표를 수행하며 50층 최종 보스 격파 | 다음 단계는 HP만 늘린 재대결 외에 목표 변화도 필요 |
| 무한 | 시간 제한 없는 생존, 일반 상점과 다른 전용 강화 | 무한 성장을 일반 원정의 불명확한 ‘계속’으로 덧붙이지 않음 |
| 돌파·타이탄 등 | 방 탈출·공용 보스·시즌 기록 등 서로 다른 정산 | 여러 모드의 경제/승리 조건을 한 판에 섞지 않음 |

첨부 5.1은 포켓몬별 클래식/러시/타워 등의 완료 기록과 해금을 구분한다. **모드 입장 조건**과 과거 패치의 **배속 기능 해금**을 합쳐 설명하지 않는다. 구 v9.0.2의 ‘15분 기록 고정 뒤에도 런이 계속될 수 있음’도 10.2 첨부의 종료 설명과 구분한다.

**해석:** 맵을 움직여 새로운 공격을 얻는 순간, 레벨업으로 그 공격에 투자하는 순간, 진화로 형태가 바뀌는 순간이 각각 보상이다. 이것들을 한 레벨업 후보 풀에 모두 섞으면 탐색의 이유와 성장의 단계감이 약해진다.

## 4. 두 게임에서 가져올 관계와 가져오지 않을 것

| 관계 | 우리의 선택 | 원작 그대로 복사하지 않는 항목 |
| --- | --- | --- |
| 캐릭터가 성장 효율을 바꿈 | 시작부터 작동하는 특성 + 레벨 성장 + 대원별 전투 사건으로 고유기 충전 | 모든 대원에게 별도 점수 숙련 3개 문턱을 강제 |
| 탐색으로 새 공격/발동 아이템 확보 | 무기 보급과 유물 이벤트가 실제 이동 목표 | 알·타입·날씨·수십 종의 통화와 장비 전부 |
| XP는 현재 빌드 투자 | 보유 무기 강화/공통 보조 선택 | 원하는 파트너를 매 레벨 자동으로 밀어주는 조립 경로 |
| 위험과 전이 | 성장 이득이 남는 동안의 공세 격화 + 명시적 출구 | 사냥 할당량 달성 후 XP를 0으로 잘라 이동을 강제 |
| 보스가 선택을 시험 | 군집·근접·사격·목표 전환을 다르게 요구 | 보스 HP를 늘리거나 무기를 압수해 성장 체감을 지움 |
| 반복 목표 | 한 판 클리어·대원별 도전·발견·조건부 난도 | 무한 기록과 일반 원정의 승리/점수 혼용 |

**최종 합체는 Woodland의 독자 규칙**이다. Burst의 ‘진화/Burst’가 곧 무기 두 개의 합체라는 근거는 없다. 사용자가 원하는 판 안의 완성 보상으로 채택하되, 재료 소비·계승·대안 빌드의 가치는 우리가 따로 검증해야 한다.

## 5. 0.8에서 확인한 구조 문제

1. 처치는 보스 자격을 채우지만 실제 XP 회수와 분리됐다. 자격 뒤 XP 제한은 ‘더 성장할지 이동할지’ 대신 ‘제한을 알고 떠날지’를 묻는다.
2. 캐릭터 숙련 분기와 무기 4단계 분기가 비슷한 이름의 연속 모달이 됐다.
3. 보스 보상·인장·공방·계속하기가 여러 화면으로 나뉘었다. 큰 성장 순간이 메뉴 처리로 쪼개졌다.
4. 두 번째 이후 보스를 모두 최종 보스로 부르면서 같은 지형을 계속했다. 원정 완료와 기록 도전의 경계가 흐렸다.
5. 일반 성장 후보가 새 무기·보유 무기·촉매를 모두 담당했고, 파트너 강화 보장으로 재료가 자동 수렴했다. 탐색은 빌드의 획득 경로보다 부수 보상이 됐다.
6. 후보 8회 자동 주행의 완주는 가능했지만, 다람쥐 집중이 산개보다 일관되게 빨랐다. 분기 선택의 재미를 입증한 결과가 아니다. [실험 기록](PROTOTYPE-V08.md)

## 6. 이번 결정과 남은 확인

- 먼저 만들 게임은 **탐색 → 빌드 투자 → 구역 보스 → 다음 구역 → 최종전 → 결과**가 끝까지 이어지는 원정이다.
- 성장 획득 창구와 승리 조건을 줄이고 맞춘다. 세부 규칙과 개발 수용 기준은 [게임 기획](GAME-DESIGN.md)에 한 번만 정의한다.
- 개별 MegaBonk 캐릭터 전원의 현행 공식, Burst 개별 진화/기술 전체표, 실제 모드별 현행 전체 시간표까지 복원했다고 주장하지 않는다.
- 10분/15분·4보스/50층은 원작을 이해하는 자료다. 우리 맵 규모와 성장량을 검증하지 않고 같은 숫자를 적용하지 않는다.
- 나무위키 이미지나 포켓몬/원작 자산을 게임 리소스로 사용하지 않는다. 기존 수호대 원화를 유지한다.
