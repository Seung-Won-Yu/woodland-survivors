# 게임 방향·UI/UX 점검 · 0.7 관찰 기록

> 2026-11-05: 아래 표는 0.7 당시 관찰 기록입니다. 새 흐름과 화면의 구현 기준은 [설계 0.9](GAME-DESIGN.md#8-화면이-설명할-일)를 따르며, 과거 개선 항목을 현재 완료 상태로 취급하지 않습니다.

2026-11-04 · 현재 0.7 로컬 시제품 대상 · 차기 기준: [게임 기획](GAME-DESIGN.md)

평가 범위는 실제 출전·전투 입력·일시정지·유물 카드·진화/합체, 보스 예고와 소스의 돌파/결과 흐름이다. 인앱 브라우저에서 실제 게임과 고정 검수실을 구분했다. 모바일은 390×844의 실제 DOM 폭을 확인한 탭을 기준으로 했으며, 다른 탭에 적용되지 않은 뷰포트나 깨진 에뮬레이션 캡처는 근거에서 제외했다. 화면 검토는 사용성 조사나 재미 검증을 대체하지 않는다.

## 방향 판단

현재는 ‘게임의 시스템들이 존재하는 상태’다. 방향이 정리됐다고 모든 시스템이 그 방향을 잘 전달하고 있는 것은 아니다. 가장 큰 문제는 기능 부재보다 **성장 목적·용어·다음 행동의 불일치**다. 이 불일치를 해결한 뒤, 대원별 성장과 선택 비용을 검증해야 한다.

새 기능을 판단할 기준:

- 대원 선택이 다음 행동·보상 선택을 바꾸는가?
- 공격의 변화와 재료 투자가 화면에서 읽히는가?
- 지금 할 일과 다음 큰 보상이 보이는가?
- 현재 힘을 시험할 위험과 다음 판에 넘을 목표가 있는가?

U01–U06은 외형을 바꾸기 전에 흐름을 정리해야 할 항목이다. U07–U10은 Impeccable의 정보 위계·실제 텍스트·일관된 토큰과 조작 상태 기준으로 해결한다. 문서에 적었다는 이유로 구현 완료로 체크하지 않는다.

## 유지할 장점

1. 원화의 캐릭터·숲과 UI의 숲색/금빛 팔레트는 구분되는 정체성이 있다. 일반적인 대시보드 테마로 교체하지 않는다.
2. 유물 카드는 역할·조건·효과·제약·연계를 분리했고, 실제 390px에서 가로 넘침 없이 선택을 읽을 수 있었다.
3. 선택 메뉴는 게임 시간을 멈추고 키보드 선택·명시적 포커스·선택 결과 피드백을 제공한다.
4. 중간/정비 상자 회수와 다음 단계 보스 카운트다운은 다음 행동을 구체적으로 알려 준다.
5. 로딩·그림 로딩 실패 안내가 있고, 대원/무기/일시정지 조작은 실제 button/select와 이름을 사용한다.

15개 사용성 관점은 목적/상태/통제/일관성/예방/인지/효율/미감/복구/도움말/조작 단서/구조/접근성/인지성/관용으로 검토했다. 오류 복구·키보드·로딩은 장점과 제한을 기록했고, 게임의 시각 전투 자체가 스크린리더만으로 완주 가능하다고 주장하지 않는다.

## 화면 규칙

| 요소 | 역할 | 디자인 규칙 |
| --- | --- | --- |
| 화면 제목 | 지금 선택하는 사건 | 이름을 크게, 한 문장 목적을 짧게 |
| 핵심 본문 | 효과·조건·손실 | meta보다 큰 글씨, 한글 줄바꿈을 실제 폭에서 확인 |
| 수치 | 단계·진척·피해·시간 | 일정한 숫자 폭과 단위; 무엇의 변화인지 바로 붙임 |
| 주 행동 | 선택/계속/출전 | 화면 구역당 우선순위 하나, 유지되는 위치 |
| 부 행동 | 보류/비교/취소 | 주 행동보다 조용하지만 터치·키보드로 접근 가능 |
| 위험 행동 | 원정 포기/종료 | 결과를 동사로 명시, 실수 방지와 되돌아갈 길 |
| 상태 | 준비/재료 부족/완성 | 색 외에 글자·표식·진척을 함께 사용 |

토큰은 기존 `:root`에서 필요한 역할만 확장한다. foreground / surface / action / state, 제목·본문·조건·meta·수치 역할을 통일한다. 새 폰트·색상 라이브러리·애니메이션 도구를 설치하는 작업이 아니다.

## 검증과 기록

실제 게임 첫 화면/입력/일시정지는 실제 입력으로, 유물·합체·보스 경고는 같은 모델·컴포넌트를 쓰는 고정 검수실로 확인했다. 검수실 화면은 실제 전체 원정 완주 증거로 사용하지 않는다.

작업공간의 화면 기록: `outputs/v07-camp-prototype.png`, `outputs/v07-fusion-book-desktop.png`, `outputs/v07-relic-mobile.png`, `outputs/v07-fusion-mobile.png`, `outputs/v07-midpoint-warning.png`, `outputs/v07-final-warning.png`.

후속 수정은 같은 화면의 desktop/mobile 전후와 실제 동작으로 확인한다. 특히 시작 무기 변경, 종료 취소, 돌파 후 새로고침, 계속 도전 후 종료, 긴 합체 카드, 화면 높이가 짧은 경우를 검사한다.
