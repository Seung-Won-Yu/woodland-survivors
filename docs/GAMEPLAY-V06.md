# 0.6 · 조합을 고르고, 다른 방식으로 싸우기

기존 원화와 3분 원정을 유지하면서 무기·유물 연계, 상대의 역할, 공격의 표현을 함께 확장했습니다.

## 참고와 설계 가설

[메가봉크 개발사 설명](https://store.steampowered.com/app/3405340/Megabonk/)의 전리품·무기 강화·아이템 시너지와 [PokéSurvivor 장비 가이드](https://pokesurvivor.com/en/items/)의 원정 중 장비 선택·유지·교체 구조를 참고했습니다. 이를 바탕으로, 같은 대원도 얻은 유물에 따라 다른 무기를 고르고 다른 위치에서 싸울 수 있게 설계했습니다. 실제 재방문 원인을 입증한 분석은 아니며 외부 코드·이미지·음원을 사용하지 않았습니다.

## 여섯 행동 연계

| 이름 | 필요한 유물 / 무기 | 실제 효과와 제한 |
| :-- | :-- | :-- |
| 왕복 기류 | wind / acorn, moon, returning | 충전 돌풍이 0.32초 후 대원을 향해 돌아옵니다. 왕복 각각 1회 적중, 총 수명 1.25초. 대원에 닿으면 종료 |
| 실타래 군집 | thread / bees, hive | 표식의 실제 이동 결산 때 추적벌 2개 생성. 각각 결산 피해의 30%, 수명 1.8초, 관통 1 |
| 가시 방벽 | shell / briar, hive | 보호막이 완전히 소진될 때만 반경 115의 반격. 부분 흡수에서는 발동하지 않음 |
| 붙잡는 덩굴 | thorn / vine | 기존 가시 파열 지점에 반경 95·1.5초 감속 지대. 추가 피해 0, 지속 제어 역할 |
| 생명 정원 | seed / lantern, bloom | 씨앗이 떨어진 자리에 반경 75·3초 피해 지대. 씨앗의 최대 2개·5초 간격 제한을 함께 사용 |
| 천둥 물결 | tide / storm | 실제 일반 회복 15의 파동 이후 가까운 적 최대 3개에 번개. 첫 대상 거리 360, 이후 연결 거리 200 |

거리·시간은 전투 모델 좌표와 초입니다. 게임의 거리 표시는 좌표 10당 1m입니다. 연계는 유물 두 칸 안에서 작동하며 무기 슬롯을 추가하지 않습니다. 무기·유물 보유를 매 발동에서 확인하므로, 교체나 합체 이후에도 실제 보유 상태를 따릅니다. 맞는 무기가 없어도 유물의 기본 효과는 유지됩니다.

모든 추가 피해는 `source: relic`입니다. 무기 적중·처치 유물을 다시 발동시키지 않습니다. 결과의 추가 피해는 기본 유물 피해와 분리합니다. 왕복 기류는 귀환 타격만, 실타래 군집은 추가 벌만, 천둥 물결은 추가 번개만 집계합니다. 덩굴은 피해량 대신 감속 지대 발동을 보여줍니다.

## 조합을 완성할 기회

시작 무기 옆에는 맞는 유물을, 유물 선택에서는 현재 무기로 완성되는 연계를 보여줍니다. 성장 선택에서는 해당 무기를 고르면 어떤 효과가 열리는지 설명합니다.

세 번째 성장 제안부터 매 세 번의 제안에, 현재 유물의 미완성 연계를 만드는 미보유 무기 후보가 있으면 하나를 포함합니다. 무기 6칸, 추방·제외, 이미 완성된 연계와 합체 소모 규칙을 지킵니다. 제안할 후보가 없으면 기존 성장 선택을 사용합니다. 나머지 제안은 기존 규칙으로 무기 강화·새 무기·보조를 섞습니다.

발견한 연계는 실제 발동 뒤 수첩에 기록합니다. 영구 능력치 보너스는 없습니다.

## 적의 역할과 공격 예고

**일반 딱정벌레**는 튼튼한 전열을 유지합니다. 85초 이후 딱정벌레 발생군의 일부가 같은 기본 능력치의 **갑각 파수꾼**으로 등장합니다. 등무늬와 크기로 구분합니다. 파수꾼은 접근 시 0.9초 동안 전방을 버틴 뒤 반경 145·각도 ±0.75라디안 충격파를 냅니다. 정면의 무기 피해는 60%로 줄고, 측후방·광역·유물 공격으로 공략할 수 있습니다. 공격 뒤 회복과 5초 재사용 간격을 둡니다.

**포자 사수**는 생성 시 정해진 역할을 유지합니다. 부채꼴 사격은 0.85초 준비 후 느린 탄 3개를 고정 방향으로 발사합니다. 낙하형은 플레이어의 당시 위치를 1초 동안 예고하고 작은 영역을 공격합니다. 일반 포자와 충격파 위험지대는 동시 3개, 충격파는 그중 최대 2개입니다. 보스 전용 공격은 별도입니다.

준비 중 조준과 경고 좌표는 고정되고, 타격 정지는 소유자의 경고 시간도 함께 멈춥니다. 경고를 낸 적을 처치하면 아직 남은 해당 위험지대가 취소됩니다. 이미 발사한 일반 포자탄은 남지만, 둥지 보스의 탄은 보스 처치와 함께 사라집니다. 취소되는 공격은 같은 프레임에 소유자가 죽어도 이후 적중하지 않습니다.

## 둥지 숲지기의 두 페이즈

시드는 첫 공격이 다른 세 순서를 선택합니다. 모두 같은 세 패턴을 사용하며 별도의 세 종 아트나 전혀 다른 능력 세트로 표현하지 않습니다.

| 패턴 | 1페이즈 | 체력 절반 이후 2페이즈 |
| :-- | :-- | :-- |
| 포자 길목 | 고정 예고 장판 3개 | 5개로 넓어진 길목 |
| 갈라지는 포자 | 고정 방향 방사탄 8개 | 10개로 촘촘해진 틈 |
| 뿌리 돌진 | 0.9초 예고 후 중심 이동 153.6 | 중심 이동 216으로 길어짐 |

공격 뒤에는 0.85~0.95초 회복 시간이 있습니다. 체력 절반 전환은 한 번이며 돌격병 2마리를 부릅니다. 이미 준비 중인 공격의 방향·강도는 전환 중에도 바뀌지 않습니다. 돌진은 시작·종료 프레임을 포함해 남은 이동 시간만 처리하고, 경고 끝에는 실제 접촉 범위를 포함하는 둥근 끝부분을 표시합니다.

둥지 활성화·처치·보상은 여전히 선택 사항입니다. 기본 능력치나 적 수를 일괄 올려서 새 패턴의 난도를 만드는 방식은 사용하지 않았습니다.

## 투사체와 타격 표현

- 도토리는 둥근 껍질·캡과 짧은 붓 모양 꼬리, 반달은 이동 방향 잔상과 귀환 시 반대 회전으로 구분합니다.
- 꿀벌은 날갯짓과 짧은 날개 잔상, 병은 포물선 높이·투척 회전, 진화 꽃씨는 별도의 홀씨 모양을 사용합니다.
- 공격 범위와 진화에 따라 탄의 시각 크기가 제한된 범위에서 커집니다.
- 적중 이펙트는 무기 출처의 색과 작은 잎·빛점·번개 기호를 유지합니다. 치명타는 짧은 별빛으로 구분합니다.
- 타격 정지·화면 흔들기를 추가로 늘리지 않고, 투사체·이펙트 상한과 상수 크기의 그리기만 사용합니다. 아군 효과가 적의 보라·붉은 공격 예고를 덮지 않게 팔레트와 투명도를 제한했습니다.

자동 검사와 모델 결과, 실제 브라우저에서 확인한 범위는 [검증 기록](VALIDATION.md)에 분리해 적었습니다.
