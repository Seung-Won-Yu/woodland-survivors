# 0.7 시제품 · 보존 상태와 검증

2026-11-04. 이 문서는 설계 0.8 구현 완료 보고서가 아니다. 기획 재정리 전에 만든 캠페인·진화·합체 실험을 버리지 않고 비교 기준으로 보관한다. 최신 기준은 [게임 기획](GAME-DESIGN.md)과 [대원 설계](CHARACTER-DESIGN.md)다.

## 현재 시제품에서 가능한 것

- 공개 게임 생성자가 3분 귀환 대신 수문장→정비→버섯왕 흐름을 사용한다.
- 수문장은 180초, 정비는 300초 이후, 버섯왕은 420초 이후다. 늦은 수문장 처치 뒤에는 90초 준비 시간을 둔다.
- 보스 상자에서 무기를 8단계·진화로 만드는 선택, 강화된 유물 연계, 왕복 산탄/보호 추적 벌떼를 선택할 수 있다.
- 진화가 합체 경로를 막지 않으며 정비 진화 뒤 가능한 합체를 이어서 고르거나 두 무기를 유지할 수 있다.
- 보스 뒤 계속 선택은 빌드 유지·90초 후 강화 보스·단계 기록 실험이다. 시간 경과만으로 자동 승리하지 않는다.
- 현재 대원은 기존 고정 특성과 고유기를 사용한다. 설계 0.8의 고유 자원·숙련 분기는 아직 없다.

무료 1→8, 6무기·6보조, 기존 XP 곱셈과 고유기 충전은 새 기획에서 재검증/교체할 항목이다. 시제품에서 잘 돌아간다는 이유로 정식 규칙으로 고정하지 않는다.

## 검증한 것

| 구분 | 근거 | 범위 |
| --- | --- | --- |
| 게임 규칙 | `npm test` 108개 통과 | 캠페인 일정·보상·승리·계속·저장, 진화·합체·유물·예고와 기존 회귀 |
| 정적 빌드 | `npm run build` 통과 | 원래 PNG 8개·폰트·모듈, 별도 전투 검수실 |
| Pages 경로 | `npm run test:pages` 3개 통과 | `/woodland-survivors/` 하위 경로·실제 PNG/WOFF2·개발 파일 제외 |
| 최신 전체 모델 | 16/16 돌파 | 6대원×desktop/mobile 12회, 합체 목표 4회, 그중 2회 3단계 유지 |
| 합체 실제 접근 | 4/4 성공 | 둥지 없이 266.5–306.7초에 두 합체 경로 완성 |
| 브라우저 | 인앱 브라우저 실제 입력 | 출전·이동·일시정지·레시피·유물·진화 후 합체 선택과 검수실 보스 경고(합체 거절 동작은 규칙 검사) |

전체 모델은 `pilot()`의 정상 메뉴 선택·이동·회피·고유기 정책을 사용했다. 시간·XP·캐릭터 능력을 바깥에서 부여하지 않았다. 두 3단계 경로는 왕복 산탄 약 641.8초, 보호 추적 벌떼 약 630.6초에 세 번째 보스를 잡고 기록을 마쳤다. 최종 HP는 모두 100이지만 30초 표본 최저는 65, 누적 피해 최대는 87이었다. 이는 무피해 검증도 재미 입증도 아니다.

같은 목표에 600프레임 공격하는 격리 실험에서는 합체의 보스·군집 피해율과 슬롯 이득을 따로 측정했다. 무적·고정 적을 쓰는 실험이므로 일반 run 결과로 표시하지 않았다. 비교 스크립트는 `scripts/weapon-bench.mjs`다. 현재 합체 화력의 장기 밸런스는 설계 0.8의 투자·분기 규칙을 붙인 뒤 다시 측정해야 한다.

## 재현

```sh
npm test
npm run build
npm run test:pages
node scripts/pilot.mjs
node scripts/weapon-bench.mjs
```

추가 경로 예:

```js
pilot({hero:'pip', weapon:'acorn', seed:9011, mode:'campaign',
  fusion:'returning', stages:3, seconds:1000,
  takeNest:false, takeRelics:true, takeTrial:true});
```

전체 결과·선택 로그·그림은 작업공간 `outputs/v07-final-model.json`, `v07-campaign-model.json`, `v07-union-before.json`, `v07-union-after.json`, `v07-tests.txt`, `v07-pages-tests.txt`, `v07-*.png`에 있다. `outputs/`는 Git/정적 배포물에서 제외한다. 공개판 0.6의 검증 기록은 [기존 기록](VALIDATION.md)에 보존했다.

## 알려진 미완성

[UX 점검표](UX-DIRECTION-AUDIT.md)의 목적/용어/종료/체크포인트 저장/긴 메뉴 문제와 설계 0.8의 성장·선택 비용은 남아 있다. 무기 변경 시 깨지던 합체 안내는 수정하고 실제 변경 동작을 확인했다. 현재 원정 저장/이어하기 UI, 온라인 기록, 설계 0.8의 새 구역/새 최종 무기는 구현됐다고 표시하지 않는다.
