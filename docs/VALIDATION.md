
모델에는 유물 제안·선택·교체와 연계의 발동·추가 피해, 적 공격 종류·피해 원천, 경험치 생성·회수·잔존량, 30초별 표본과 이동이 막힌 시간을 기록했습니다. 여섯 연계 모두 실제 발동이 관측됐고, 파수꾼 충격파는 총 422회 기록됐습니다. 일부 경로에서 막힌 시간이 최대 36초였으므로 최적 경로를 보장하는 주행은 아닙니다.

초기 새 패턴 검사에서 기본 경로 세 건이 패배했습니다. 충격파 역할을 모든 딱정벌레에 주던 것을 별도 파수꾼으로 분리하고, 공격 간격·동시 위험지대 수를 조정했습니다. 이후 전체 42회를 다시 실행해 모두 귀환했습니다. 전체 결과는 개발 작업공간의 `outputs/first-three-minutes-v6.json`, 요약은 `outputs/V6-MODEL-REVIEW.txt`에 보관합니다. 이 파일들은 정적 게임에 포함하지 않습니다.

기본 여섯 대원 주행은 `node scripts/pilot.mjs`로 실행할 수 있습니다. 별도 조합은 이 모듈의 `pilot({hero, weapon, seed, takeNest, takeRelics, takeTrial, relicPreference, combatStyle, view})`를 사용합니다. 기본 정책은 유물·제단을 건너뜁니다. 시너지 조합은 기본 여섯 유물 우선순위에서 목표 유물을 맨 앞에 둡니다.

계획 빌드는 다람쥐/도토리/바람/seed2, 토끼/꿀벌/실타래/seed1, 고슴도치/가시/갑주/seed2, 두더지/덩굴/가시매듭/seed1437, 수달/병/생명씨/seed1437, 여우/번개/물결/seed9011입니다. 갑주 조합은 나무껍질 장비와 안전할 때 잠깐 정지하는 `combatStyle: anchor` 입력을 사용했습니다.

## 브라우저에서 확인한 내용

Codex 인앱 브라우저의 데스크톱과 390×844 모바일에서 시작 무기별 연계 안내, 긴 유물 비교창, 성장 선택의 연계 완성 미리보기와 HUD를 확인했습니다. 실제 입력으로 반달·반딧불 병 조합과 번개·꿀벌 조합을 플레이하고, 숲지기의 예고 장판·돌진 경로·방사탄·2페이즈·처치 이후 보상을 확인했습니다. 여우 원정에서 실타래 군집의 실제 발동도 일시정지 수치로 확인했습니다. 기존 0.5에서는 모바일 스틱과 제단 20초·두 번째 유물 회수 흐름을 직접 확인했습니다.

전체 귀환 성공률, 모든 연계의 수치·방어·발동 경계, 일반 파수꾼의 피해와 여섯 보스 주행은 자동 검사·모델 결과입니다. 브라우저 입력 검증과 혼동하지 않습니다. 스크린샷은 README와 `docs/images/`에 있습니다.

모델 성공률은 모든 무기·시드의 균형이나 사람이 느끼는 재미를 보장하지 않습니다. 플레이 가능한 범위는 첫 3분 정찰이며, 30분 전체 원정과 영구 성장·원정 저장 UI는 검증 대상이 아닙니다.
