# 0.4 검증 기록

게임 규칙 검사와 모델 주행, 실제 브라우저 검증을 구분해 기록합니다.

## 자동 검사

```sh
npm test
npm run build
npm run test:pages
```

- 게임 규칙 38개: 무기 피해·밀침·타격 반응, 보행·충돌·회피, 성장·진화·합체, 보급·샘·둥지·귀환, 피격음 우선순위와 경험치 보존 등
- Pages 검사 3개: 저장소 하위 경로의 HTML·JS·CSS 의존성, 실제 PNG·WOFF2, 개발 기록을 제외한 정적 배포물
- `docs/motion-lab.html`: 실제 게임용 아틀라스와 24개 대원·방향 조합의 보행 프레임 검사

## 첫 3분 모델 주행

2026-11-03 기준, 고정 1/60초 간격의 동일한 이동·회피·성장 선택 정책으로 실행했습니다. 게임 외부에서 시간·경험치·능력치를 보정하지 않았습니다.

| 조건 | 대원·시드 | 결과 | 최저 레벨 / 체력 |
| :-- | :-- | :-- | :-- |
| 데스크톱 · 둥지 미방문 | 6대원 × 1437·9011·2026 | 18/18 귀환 | Lv.16 / HP 72 |
| 모바일 · 둥지 미방문 | 6대원 × 1437·9011 | 12/12 귀환 | Lv.18 / HP 28 |
| 데스크톱 · 둥지 도전 | 6대원 × 1437 | 6/6 처치·상자 회수·귀환 | Lv.16 / HP 91 |

둥지 미방문 30회에서는 둥지를 활성화하거나 둥지 상자를 얻지 않았습니다. 모바일 모델은 390×844 화면과 줌 0.8에 해당하는 월드 뷰를 사용했습니다. 모델에는 경험치 생성·회수·잔존량, 피해 원천과 30초별 성장 표본을 기록합니다.

기본 여섯 대원 주행은 `node scripts/pilot.mjs`로 실행할 수 있습니다. 별도 조합은 이 모듈의 `pilot({hero, seed, takeNest, view})`를 사용합니다.

## 브라우저에서 확인한 내용

1280×720 데스크톱과 390×844 모바일에서 실제 키보드·터치 입력, 대원·무기 선택, 성장 선택, 보급 경비·장비 회수, 둥지 활성화·공격 예고, 일시정지·결과 표시를 확인했습니다. 0.4의 브라우저 검증은 초반 조작과 표시 확인이며, 위의 전체 귀환 수치는 모델 주행 결과입니다.

모델 성공률은 모든 무기·시드의 균형이나 사람이 느끼는 재미를 보장하지 않습니다. 플레이 가능한 범위는 첫 3분 정찰이며, 30분 전체 원정과 영구 성장·원정 저장 UI는 검증 대상이 아닙니다.
