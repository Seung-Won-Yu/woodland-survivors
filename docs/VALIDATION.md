# 0.5 검증 기록

게임 규칙 검사와 모델 주행, 실제 브라우저 검증을 구분해 기록합니다.

## 자동 검사

```sh
npm test
npm run build
npm run test:pages
```

- 게임 규칙 57개: 기존 전투·성장·모션·귀환 규칙 38개와 유물·도전·원정 기록 19개
- 추가 규칙은 실제 이동 충전, 여섯 유물의 피해·보호막·회복, 고유기/유물 연쇄 차단, 두 칸 교체, 명시적 꾸러미 상호작용, 제단 예고·중단·완료·경험치 보존, 시드 결정성, 저장 검증·적 탄환 복원, 수첩 중복 방지를 포함합니다.
- Pages 검사 3개: 저장소 하위 경로의 HTML·JS·CSS 의존성, 실제 PNG·WOFF2, 개발 기록을 제외한 정적 배포물
- `docs/motion-lab.html`: 실제 게임용 아틀라스와 24개 대원·방향 조합의 보행 프레임 검사

## 첫 3분 모델 주행

2026-11-04 기준, 고정 1/60초 간격으로 36회를 실행했습니다. 게임 외부에서 시간·경험치·능력치·적을 보정하지 않았습니다. 단위 검사에 사용하는 격리용 전투 상태와 이 모델 주행을 구분합니다.

**36/36 귀환, 제단 도전 18/18 완료.** 둥지 미방문 30회에서는 둥지를 활성화하거나 둥지 상자를 얻지 않았습니다. 모바일 모델은 390×844 화면과 줌 0.8에 해당하는 월드 뷰를 사용했습니다.

모델에는 유물 제안·선택·교체와 실제 발동·피해·회복·방어, 경험치 생성·회수·잔존량, 피해 원천, 30초별 성장 표본과 이동이 막힌 시간을 기록했습니다. 시드별 지형과 선택 정책에 따라 일부 경로에서 막힌 시간이 최대 30.6초였으므로, 최적 경로를 보장하는 주행은 아닙니다.

최종 보고서에는 제단 주변 경험치 회수 보완 이후 영향을 받는 18회를 다시 실행한 결과와, 영향을 받지 않는 기본 경로 18회를 함께 사용했습니다. 전체 결과는 개발 작업공간의 `outputs/first-three-minutes-v5.json`, 요약은 `outputs/V5-MODEL-REVIEW.txt`에 보관합니다. 이 파일들은 정적 게임에 포함하지 않습니다.

기본 여섯 대원 주행은 `node scripts/pilot.mjs`로 실행할 수 있습니다. 별도 조합은 이 모듈의 `pilot({hero, seed, takeNest, takeRelics, takeTrial, relicPreference, view})`를 사용합니다. 기본 정책은 유물·제단을 건너뜁니다. 모바일 도전은 `relicPreference: ['seed','tide','shell','thorn','thread','wind']`를 사용했습니다.

## 브라우저에서 확인한 내용

Codex 인앱 브라우저의 1280×720 데스크톱과 390×844 모바일에서 시작 화면, 실제 키보드·스틱 입력, 성장 선택, 보급 경비·장비 회수, 명시적 유물 상호작용과 장착, 반응형 선택창·HUD를 확인했습니다. 직접 입력으로 제단을 시작해 20초를 버티고, 추가 꾸러미에서 두 번째 유물을 장착했습니다. 바람·가시 유물이 실제로 발동하고 일시정지 수치에 표시되는 것도 확인했습니다. 해당 경로의 브라우저 오류 로그는 없었습니다.

전체 귀환 성공률, 모든 유물과 교체의 수치 검증, 최종 제단 경험치 회수 보완은 자동 검사·모델 결과입니다. 브라우저 입력 검증과 혼동하지 않습니다. 스크린샷은 README와 `docs/images/`에 있습니다.

모델 성공률은 모든 무기·시드의 균형이나 사람이 느끼는 재미를 보장하지 않습니다. 플레이 가능한 범위는 첫 3분 정찰이며, 30분 전체 원정과 영구 성장·원정 저장 UI는 검증 대상이 아닙니다.
