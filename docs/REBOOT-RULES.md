# 재기획 세부 규칙 — 개발 계약 1.1

2026-11-06 · 시제품 일부 구현 / 확장 명세 · 상위 방향: [재기획](REBOOT-DESIGN.md) · 전투 수치: [콘텐츠 명세](REBOOT-COMBAT.md) · 화면/검수: [UX·수용 기준](REBOOT-UX-QA.md)

## 3. 성장·교체·조립의 정확한 비용

- XP 레벨은 L1에서 시작하며 레벨업마다 투자 1회다. 무기 레벨은 XP 레벨과 별개다.
- 새 총의 기본 레벨은 구역 1/2/3에서 L1/L2/L3. 빈칸과 교체 모두 같은 바닥값을 적용한다. 의도한 후반 따라잡기다.
- 모듈 획득·중복·XP 강화는 같은 `rank 1..3`을 바꾼다. 희귀도는 보상 묶음의 등급이며 장착 후 별도 영구 배율로 중첩되지 않는다.
- LV.6 대원 분기는 무료다. 그 화면에서 일반 성장 1회와 함께 확정하며 독립 XP 투자로 세지 않는다.
- 초반 개장은 첫 보스 도전 **전**까지 한 번. `새 무기 레벨=min(5, 기존 레벨)`이며 L4 이상이면 새 총 분화를 같은 교체 화면에서 고른다. 첫 보스 도전 후에는 남은 무료 개장이 만료된다. 진화/합체 완성물에는 사용하지 못한다.
- 일반 교체는 `min(5, 구역 기본 L + floor(max(0, 기존 L - 구역 기본 L)/2))`. 결과 L4 이상이면 새 분화를 고른다. 교체·분화를 한 거래로 확정하고 취소는 아무것도 소비하지 않는다. 기본 레벨을 제외한 초과분만 이전하므로 같은 구역의 반복 교환으로 레벨을 늘릴 수 없다.
- 장착한 동일 ID 총을 또 획득하지 않는다. 합체 결과가 가진 재료 태그는 소유 ID로 보지 않는다. H를 합체한 뒤 다시 H를 얻는 것은 허용한다. 같은 합체 결과 ID의 중복 소유는 금지한다.

### 조율권

장비 패널에 수량과 가능한 조립을 항상 표시한다. 조건을 충족하면 HUD에 `조립 가능` 한 개를 표시한다. G/장비 버튼으로 전투를 멈추고 확인한다. XP 선택·필드 보상 선택이 열려 있으면 이를 해결한 뒤 조립한다. 거절/닫기는 권리·재료를 소비하지 않는다.

| 사용 | 조건 | 소비 | 유지 |
| --- | --- | --- | --- |
| 단일 진화 | 총 L6·허용 모듈 2강화 이상 | 조율권 1개 | 무기 칸·모듈·분화 |
| 태그 합체 | 서로 다른 미완성 총 L4 이상·유효 태그 쌍·모듈 2강화 | 두 총·조율권 1개 | 공용 모듈, 주공격 문법·분화, 보조 페이로드, 빈 무기 칸 |
| 모듈 조율 | 장착 모듈 중 3강화 미만 | 조율권 1개 | 지정 모듈 +1강화 |
| 응급 정비 | 최대 HP 미만 또는 추가 최대 HP를 원함 | 조율권 1개 | 최대 HP +15·현재 HP +35(최대 이내) |

조율권 교환은 조립 패널에서 언제든 가능하다. 소비 후 되돌리지 않는다. 따라서 비진화 시너지 빌드도 **첫 보스 전** 조율권을 사용할 수 있다. 총을 단순 +1레벨 하는 교환은 제공하지 않는다.

중간 보스의 추가 보상은 조율권1과 HP15 회복뿐이다. 무기/모듈 +1 카드는 지급하지 않는다. 시제품 보스와 최종 보스는 권리/회복을 추가하지 않는다. 보스가 죽은 틱에 대원도 죽으면 회복으로 부활시키지 않는다. 회복·권리·출구 플래그는 같은 보스 완료 거래로 기록한다.

## 4. 합체가 하나의 정답으로 수렴하지 않게 한다

합체 계열은 발동 규칙이다. 완성 총 ID는 `계열:주공격ID:주분화:보조ID:보조분화`로 구분한다. 재료를 선택할 때 필요한 태그를 어느 총이 담당하는지 표시한다. 한 총이 두 필요 태그를 모두 가진 경우에도 다른 총이 나머지 역할을 맡아야 한다. 양쪽 배치가 모두 유효하면 주공격 방향을 고른다.

첫 시제품의 전도 계열은 `탄환 제공 총=주공격`, `폭발 제공 총=페이로드`다. **주공격은 해당 총의 L6 일반 공격을 기반**으로 하며 단일 진화의 전용 공격까지 가져오지 않는다. H는 연사, P는 직선 정밀탄, S는 부채꼴 산탄을 유지한다. 재료가 R이면 주기적 폭발에 추적/연소 분화를 계승한다. 이미 진화한 총은 재료로 고를 수 없다.

H+R 첫 실험은 가중 적중 10마다 페이로드 1회, 내부 간격 0.6초, 피해 80·반경 130으로 시작한다. 산탄은 한 번 발사한 것을 여러 개의 완전 적중으로 세지 않는다. 재료 L4 초과분은 합계 한 단계당 주공격 간격 −3%, 최대 −12%로 전승한다. 모듈의 추가 폭발이 새 페이로드를 재발동하지 않는다.

확장 합체의 재료 조합마다 새 완성 원화가 필요한 것은 아니다. 주공격의 탄 궤적·발사 주기·사거리와 페이로드의 예고/폭발이 구별되어야 한다. P+R과 S+R이 같은 총처럼 보이고 싸운다면 확장 합체는 통과하지 못한다.

## 5. 후보 생성 순서

모든 선택은 최대 3개의 **서로 다른 결과**를 제시한다. 재료 ID만 다른 동일 회복 카드를 세 장 만들지 않는다. 후보 생성의 순서는 `자격 필터 → 보장 자리 → 나머지 추첨 → 중복 제거/대체 → 저장 → 표시`다. 적용 불가 카드를 그럴듯한 이름으로 내지 않는다.

### 5.1 필드 무기 보급

| 자리 | 생성 | 대체 |
| --- | --- | --- |
| A 보유 투자 | 미완성·L6 미만 보유 총 중 균등 추첨. L3 총이면 두 분화를 하위 선택으로 제공 | 유효 장착 모듈 +1 → 회복/탄약 |
| B 새 총 | 미보유·미제외 기본 총 중 균등 추첨. 첫 두 보급에서는 이미 제시한 새 총 제외 | 유효 모듈 획득/강화 → 회복/탄약 |
| C 모듈 | 현재 공격 태그에 즉시 맞는 기본 모듈 중 균등 추첨. 첫 두 보급에서는 완성에 기여하는 모듈 우선 | 유효 장착 모듈 +1 → 회복/탄약 |

첫 새 총을 골랐다면 두 번째 보급 C는 그 총에 즉시 유효한 모듈을 우선한다. 첫 보급의 R/F 선택을 강제로 합체 파트너까지 완성시키지 않는다. XP에는 해당 새 총의 유효 강화가 들어갈 수 있어야 한다. 모듈 4칸이 차도 교체가 가능한 후보는 유효하되 잃을 효과를 표시한다.

### 5.2 XP 성장

필드 무기 보급의 모듈 카드는 기본 1강화다. 선택 무기고만 75/22/3 희귀도 표를 사용한다. 고유 모듈인 불안정 과급기는 XP/중복으로 강화하지 않고 제외 후보에도 올리지 않는다.

1. A는 유효한 보유 총 강화 중 균등 추첨한다. 최근 두 XP 화면에 없었던 총이 있으면 그것을 먼저 고르고, 동률이면 균등 추첨한다. 모든 총이 최대면 장착 모듈 유효 강화로 대체한다. 제시 이력은 총 ID 기준이며 같은 총의 레벨이 올랐다고 이력을 초기화하지 않는다.
2. B는 A와 다른 유효 보유 총/장착 모듈 강화의 합집합에서 균등 추첨한다. 같은 총 L4의 두 분화가 A/B를 모두 차지하지 않도록 분화 선택은 카드 내부에 둔다.
3. C는 생존 보정 `최대 HP +6·회복 +6` 또는 회수 보정 `회수 반경 +10` 중 추첨. 회수 보정은 3회 상한이며 총/모듈도 모두 최대면 9절 추가 성장으로 전환한다.
4. 유효 강화가 하나만 남으면 A + 생존/회수 대안을 제시한다. 부족한 후보를 채우기 위해 새 총이나 자동 합체를 끼워 넣지 않는다.

### 5.3 재추첨·제외·건너뛰기

- b03 재추첨은 **XP/필드 무기 보급/선택 무기고/습격 성공 보급**에서 판당2회를 공유한다. 전체3후보를 같은 규칙으로 다시 만들고1회를 소비한다. 모듈 상자의 품질·강화 묶음은 유지하고 내용만 바꾼다. 보스·조립에는 적용하지 않는다.
- 제외1회도 위 선택 화면에서 공유한다. 모듈 상자에서 한 후보를 제외해 바꿀 때 기존 품질과 강화량을 유지한다. 현재 상자를 건 뒤에는 습격 결과 보상을 받을 때까지 후보 제어를 다시 열지 않는다.
- 재추첨 후에도 첫 두 보급의 새 총 중복 방지를 유지한다. 풀이 소진되면 반복 제시 대신 유효 모듈로 대체한다. 새 ID 2종을 이미 보여 줬다면 그 안전 조건은 달성된 것으로 기록한다.
- 제외는 아직 보유하지 않은 정확한 무기/모듈 ID 하나를 그 판의 이후 풀에서 제거한다. 계열 전체를 지우지 않는다. 현재 장비·그 장비의 분화·보스 보상·정비·조율권은 제외 불가다.
- 첫 두 보급이 끝나기 전에는 새 총 2종 제시를 불가능하게 만드는 제외를 허용하지 않는다. 초기 시제품처럼 미보유 총이 둘뿐인 풀에서는 초반 총 제외가 잠기고 이유를 표시한다.
- 제외는 선택을 끝내지 않는다. 그 자리만 다시 생성하고 횟수를 소비한다. 후보 희귀도는 바꾸지 않는다.
- 건너뛰기는 선택을 버리고 현재 최대 HP의 5% 회복(HP가 가득 차면 전술기 충전 5)만 받는다. 상자 희귀도·레벨업 권리는 소모한다. 같은 상자를 닫았다 다시 열어 결과를 바꾸는 기능은 없다. Esc는 선택을 보존한 일시정지다.

## 6. 선택 무기고와 증폭 습격

안전 상자는 일반75/희귀22/원형품3%, 보급차 습격 성공은70/27/3%, 장갑 습격 성공은40/45/15%로 **상자 희귀도를 한 번** 뽑는다. 희귀도는 상자당 동일하며 카드마다 따로 뽑지 않는다. 일반은 모듈1강화/기존+1, 희귀는2강화/기존+2, 원형품은 미보유 고유품 한 장+호환 모듈 즉시3강화 대안이다. 계약 선택은 습격 횟수를 따로 늘리지 않으며 구역당 둘 중 하나만 한 번 고른다.

원형품이면 미보유 불안정 과급기를 후보 1번에 **확정**한다. 고유품을 또 뽑는 숨은 확률은 없다. 보유 중이면 중복 고유품 대신 호환 3강화로 대체하고 UI에 `고유품 보유 중`을 표시한다. 나머지 후보에도 현재 빌드에 유효한 강화가 최소 하나 있어야 한다. 꽉 찬 4모듈은 교체 손실을 표시한다. 모든 모듈이 최대면 미리 표시한 대체 보급(전술기 완충/회복/최대 HP)으로 전환한다.

상자는 공개하는 시점에 후보·희귀도·난수 상태를 저장한다. 모듈을 고르면 즉시 확보 거래가 된다. 선택 전에는 전체 상자를 습격에 걸 수 있다. 현재 후보 중 하나와 성공 상자 둘을 함께 받지 않는다.

### 습격의 상태

`offered → wager-committed → active → success-pending-choice / failed / withdrawn → resolved`

- 시작: 공개된 보급차/장갑 계약을 고르고 안전 상자를 담보로 잠근다. 선택 계약·HP·경로·호위·성공 보상 희귀도/난수 씨앗을 저장한 뒤 전투를 시작한다. 시작 전에는 취소 가능, 시작 후에는 철수다.
- 성공: 수송차 HP 0, 플레이어 생존. 확정해 둔 성공 희귀도와 현재 장비로 호환 후보를 생성·저장한 뒤 보상을 고른다. 원래 상자는 폐기한다.
- 실패: 수송차가 탈출선을 넘거나 플레이어가 철수. 상자만 소실하고 재도전하지 못한다. 이미 얻은 XP·다른 보급은 유지한다.
- 수송차와 호위는 기존 위험과 함께 싸운다. 철수 후 수송차는 떠나지만 남은 호위·이미 예고된 포격은 유지한다. 즉시 회복·무적·전체 적 제거를 주지 않는다.
- 구역당 한 번. 습격 성공은 300점/40C, 잔류 위험 D나 시간 압박 P를 직접 올리지 않는다. 시제품은 C를 실제 지급하지 않는다.

## 7. 전투 상태·시간·기록 위험

| 상태 | 가능 행동 | 불가 행동 |
| --- | --- | --- |
| field | 이동·공격·보급·습격·보스 도전·조립 | 구역 보스 미격파 상태의 다음 구역 이동 |
| boss | 이동·공격·조립·메뉴 중도귀환 | 필드 습격 시작·미격파 출구 이동 |
| holdout | 남은 보급·조립·증원 도전·열린 출구 | 같은 보스 보상 재수령·새 조율권 생성 |
| choice/paused/saving | 해당 UI 결정·저장 재시도 | 시간·적·투사체·충전 진행 |
| terminal | 결과 확인·재출격 | 전투 재개·조립·보상 선택 |

기본 공세 압박 P는 보스 전 구역 전투시간 60초마다 +1, 보스 격파 뒤에는 당시 P에서 잔류 30초마다 +1이다. 다음 상승 5초 전에 예고한다. 다음 구역은 P=0. 이는 점수를 주지 않는 세계 압박이다. 일시정지/선택/배경 탭은 시간을 멈춘다.

습격·보스전·잔류 도전은 동시에 하나만 진행한다. 습격 중 보스 도전은 ‘습격을 끝내거나 철수’ 안내를 표시하고, D 도전 중에는 남은 상자의 새 습격을 시작하지 못한다. XP/장비/일반 보상 선택은 진행 중 사건도 함께 멈춘다. 열린 출구로 떠나면 진행 중 습격/D는 철수 처리한다.

잔류 도전 D는 보스를 잡은 뒤 출구 근처의 `증원 호출`로 시작한다. 지휘관 둘과 지정 호위대를 소환하며, 지정 지휘관 격파로 완료한다. 일반 배회 적 전멸을 요구하지 않는다. 성공하면 해당 구역×D의 보너스 500×D를 확정하고 다음 D가 열린다. 실패/철수는 그 구역의 해당 D를 닫고 다음 도전을 열지 않는다. 진행 중에도 출구는 열려 있다. 출구로 떠나면 미완 도전은 철수로 처리한다.

시제품은 D1 한 번만, 정식 작전은 D를 계속 올릴 수 있다. D의 공세는 시간 압박 P 위에 더해진다. 별도 새 모드/별도 통화는 만들지 않는다. 최종 보스 후에는 남은 상자와 증원 도전만 남고 새 무기 보급·조율권을 무한 생성하지 않는다.

## 8. 같은 프레임의 판정 순서

시뮬레이션 한 틱 안의 결과는 다음 순서로 확정한다. 체력 0에 도달한 대원은 같은 틱의 보상 회복으로 부활하지 않는다.

1. 이미 탈출선을 넘은 수송차는 실패 확정 후 공격 대상에서 제외한다. 같은 틱의 뒤늦은 탄으로 성공시키지 않는다.
2. 이동·공격·위험 판정을 모두 처리하고 사망 표적을 확정한다. 일반 적/부위/보스는 고유 ID당 한 번 처치로 센다.
3. 처치 XP·점수·고유 사건 성공을 확정한다. 보스와 대원의 동시 사망도 보스 격파 기록·수당 근거는 남는다.
4. 대원 사망이면 즉시 실패 결과. 새 선택 화면·다음 구역·귀환 입력을 처리하지 않는다. 성공한 습격의 점수/수당은 남지만 미선택 모듈은 장착/발견으로 세지 않는다.
5. 생존한 경우에만 보급/레벨업/보스 보상/조립 UI를 연다. 큐 우선순위는 보스 상태 전환 → 이미 확보한 필드 보상 → XP 성장 → 새 조립 요청이다. 같은 보상 ID를 두 번 처리하지 않는다.
6. 최종 보스 플래그가 있고 살아 있는 상태에서 귀환을 확정해야 완주다. 귀환 처리 직전 같은 틱의 사망이 있었다면 완주하지 않는다.

고유 퀘스트의 ‘격파’와 ‘완주’를 따로 판정한다. 중간 보스를 잡고 죽은 판의 격파 도전은 진척될 수 있으나 완주 도전·최초 완주 수당은 지급하지 않는다.

## 9. XP 예산과 추가 성장

설계 데이터의 `xpCosts`는 **현재 LV.1→2부터 LV.17→18**까지의 비용이다. 누적 XP는 LV.7=91, LV.8=119, LV.9=151, LV.14=387, LV.18=680이다. 회수한 XP만 레벨로 바뀐다. 보급에서 받은 총·모듈은 XP 레벨을 소비하지 않고 그 보급 선택을 소비한다.

| 보스 전 빌드 증명 경로 | 필드 선택 두 번 | 필요한 XP 투자 | 첫 조율권 사용 |
| --- | --- | --- | --- |
| H 단일 진화 | R 확보, 도탄기 1강화 | H +5, 도탄기 +1 = 6회 / LV.7 | H 진화 |
| H+R 전도 합체 | R 확보, 축전 코일 1강화 | H +3, R +3, 코일 +1 = 7회 / LV.8 | 전도 합체 |
| H+F 촉매 연계 | F 확보, 촉매 연료 1강화 | H +3(유탄), F +3, 촉매 +1 = 7회 / LV.8 | 촉매 2→3강화 |

위 표는 **가능한 선택열과 예산의 증명**이다. 모든 시드에 이 순서·아이템이 보장된다는 뜻이 아니다. 필요한 기본 모듈이 안 나온 판에서도 현재 무기를 키울 수 있으며 첫 위험 보급이 추가 방향 전환 기회다. 일반 보상만 가정했고 희귀·원형품은 투자 예산의 추가 이득이다. 보스 전 두 종류 완성물을 동시에 만드는 것은 시작 조율권 1개 때문에 불가능하다.

LV.18 이후 XP 비용은 `90 + 7×(현재 LV−18)`이다. 장비에 유효 강화가 남아 있으면 계속 같은 규칙으로 투자한다. 공격·모듈이 모두 최대라면 추가 성장 3후보를 제시한다: `기본 화력에 +1% 가산`, `최대 HP +2·회복 +2`, `전술기 충전 +10`. 화력은 매번 1.01배로 곱하지 않는다. XP·레벨은 끊지 않되 공세 압박의 역할 변화와 증가를 계속 감당해야 한다. 시제품에서는 이 구간을 장기 밸런스가 검증된 것으로 취급하지 않는다.

## 10. 점수·C·해금

점수 원장은 `지역/사건/표적/단계` 고유 ID로 지급한다. 숫자는 데이터의 `score`를 따른다. 보스 점수·사건 점수·습격 점수·D 보너스는 서로 다른 근거이며 동일 사건을 여러 이름으로 중복 집계하지 않는다. 예를 들어 선택 지휘관을 잡아 무기고를 열면 사건 400점, 그 상자를 건 습격 성공은 추가 300점이다. 상자를 받았다는 이유로 사건 400점을 다시 주지 않는다.

정식 작전의 반복 C는 다음을 합한다. 일반 적과 정예는 별도로 세며 정예를 일반 적 수당에 다시 넣지 않는다.

```text
floor(min(일반 처치, 900) / 15)
+ min(정예 처치, 9) × 10
+ min(고유 사건 완료, 6) × 40
+ 격파한 구역 보스의 수당 [90, 120, 180]
+ 살아서 최종 귀환했으면 120
+ min(습격 성공, 3) × 40
+ min(완료한 구역×D 도전 수, 3) × 20
+ 계정 최초 정상 완주면 200 (일회)
```

반복 수당 최대 1,080C, 첫 정상 완주를 포함한 최대 1,280C다. 오래 잔류해도 같은 판의 현금 상한을 늘리지 않는다. 일반 처치·단계 기록 점수와 C의 상한은 다르다. 점수는 C로 환전하지 않는다. 실패/중도귀환도 이미 완료한 근거는 정산하지만 완주 120C와 첫 완주 200C는 없다. 새 판을 열고 바로 귀환하면 성과도 수당도 0이다.

| 첫 연구 후보 | 조건·가격 | 다음 판에 생기는 다른 선택 |
| --- | --- | --- |
| 응급 주사기 | 첫 정상 완주 / 300C | 정예 처치 회복 모듈 후보. 4칸 중 무엇을 빼고 안전성을 얻을지 선택 |
| 분열 수류탄 | 전도 합체 상태로 구역 보스 격파 / 350C | 폭발 뒤 작은 2차 파쇄탄. 발동 재귀 없이 넓은 추격대 공략 |
| 흡열 코일 | F 단일 진화 상태로 구역 보스 격파 / 350C | 연소 대상 전기 적중이 보급 충전에 기여. 다음 판 연소+축전 조합을 노림 |

기본 총·모듈·분화·진화·합체는 연구 전부터 쓸 수 있다. 연구는 선택권을 늘리고 장착 비용은 모듈 한 칸이다. 새 연구는 **조건을 충족하는 첫 필드 모듈 후보**에 한 번 우선 제시한다. 흡열 코일처럼 복합 조건이면 필요한 공격·모듈이 없을 때 무효 카드를 내지 않는다. 아직 제시하지 못한 체험 권한은 다음 판까지 보존한다. 세 연구를 모두 연 뒤에도 다른 빌드·위험·기록 때문에 다시 플레이하는지 별도로 검증한다.

계정 기록 키는 `ruleset / balanceRevision / mode / hero / difficulty`다. 시드는 상세 재현 정보이며 시드별로 최고 기록을 쪼개지 않는다. 최고 점수·최고 완료 D·최단 정상 완주를 별도 저장하고 최근 10판의 장비·분화·선택·실패 원인을 남긴다. 시제품과 정식 작전, 0.15 기록은 합치지 않는다. 비교에 영향을 주는 밸런스 변경은 revision을 올리고 이전 기록을 보관한다.

## 11. 저장의 거래 경계

난수는 map/supply/combat/loot 네 흐름으로 분리한다. 맵 생성 시 상자의 희귀도 씨앗을 정하고, 실제 첫 공개 때 현재 장비의 호환 후보를 만든다. 전투 RNG를 더 소비하거나 지도를 여는 것으로 보상 품질이 달라지지 않는다. 현재 무장에 맞게 후보가 달라지는 것은 의도된 빌드 선택이고, HP·연패에 따라 숨겨진 희귀도 확률을 바꾸지 않는다.

| 거래 | 한 번에 저장해야 할 것 | 저장 실패 시 |
| --- | --- | --- |
| 새 출격 | sequence·runId·seed·계정 스냅샷·초기 조율권 | 기존 로비 유지, 전투 시작하지 않음 |
| 카드 최초 공개 | 상자/레벨 ID·후보·희귀도·난수·입력 잔량 | 내용을 공개하지 않고 재시도 |
| 재추첨/제외 | 변경된 후보·소비 횟수·제외 ID·난수 | 이전 후보/횟수 유지 |
| 장비/조립 | 소비 ID·결과 무기·분화·모듈·권리·빈칸 | 이전 장비 유지, 이중 소비 금지 |
| 습격 시작 | 담보 상자·경로/수송차 진행·성공 품질 씨앗·습격 ID | 원래 상자 선택 유지, 전투 시작하지 않음 |
| 습격 성공 | 완료 ID·점수/수당 근거·미선택 후보 | 같은 결과로 재시도, 새 추첨 금지 |
| 보스 격파 | bossCleared·finalBossDefeated·보상 지급 ID·출구 | 마지막 안정 상태부터 복구, 중복 지급 금지 |
| 귀환 정산 | 전체 결과·wallet·해금·기록·정산 sequence·activeRun 해제 | 결과를 미확정 상태로 유지, 같은 정산을 재시도 |

진행 중 판은 5초마다 안정된 틱 경계에서 체크포인트를 만든다. 앱이 배경으로 가면 일시정지·저장한다. 재개는 항상 정지 상태다. 공격 판정 중간·사망 처리 중간의 반쪽 상태는 저장하지 않는다. 주기 저장 실패도 정지하고 재시도/기지 복귀 방법을 표시한다. 마지막 저장까지 잃을 수 있는 진행을 숨기지 않는다.

최소 저장 필드: `schema/ruleset/revision`, `profileId/runId/sequence`, `mode/region/phase`, `inventory/tuning/controls`, `heroBranch`, `rngStreams`, `pendingChoices`, `wager`, `worldPressure/holdoutChallenge`, `bossCleared/finalBossDefeated/extracted`, `rewardLedger`, `stats`, `resultReceipt`다. 전체 전투 체크포인트에는 적·탄·위험·쿨다운·XP도 포함한다.

한 프로필은 동시에 한 작성자만 갱신한다. 두 탭의 revision이 다르면 늦은 탭은 진행을 멈추고 최신 저장을 다시 읽는다. 클라이언트 간 원자 갱신 방법은 지원 브라우저에서 검증해야 한다. revision 숫자만으로 동시 쓰기가 완전히 안전하다고 가정하지 않는다.

## 12. 기존 계정 이관의 경계

기존 `operation-breakwater-profile-v1`은 별도 보관한다. 시제품 키는 `operation-reboot-prototype-v1`, 정식 키는 `operation-reboot-profile-v1`로 구분한다. 시제품은 이관하지 않는다. 정식 작전 출시 시 한 번만 아래 계약을 적용한다.

1. 기존 활성 판이 있으면 이전 버전에서 계속하거나 정상 정산하는 선택을 먼저 제공한다. 이관 때문에 미완료 판에 자동 승리·보너스를 만들지 않는다.
2. 기존 wallet을 복사하고 훈련은 `paid[]`의 실제 합계를 환불한다. 훈련 rank에 현재 가격을 곱하지 않는다.
3. 기존 연구는 지불 이력이 별도로 없으므로 ‘실제 지불액’이라고 추정하지 않는다. 확인 가능한 0.15 고정 가격표의 **이전 보상**을 제공한다: P 분열 200, H 도탄 240, R 점화 280, P 약점 360, H 축전 360, S 플레셰트 220, F 촉매 260, R 전도 300C. ID당 한 번만 적용한다. 미확인 버전/손상 데이터는 임의 계산하지 않는다.
4. 이전 설정·해금 대원·과거 기록은 보존하고 새 규칙 기록과 분리한다. 새 기본 모듈은 모든 계정에 제공한다. 기존 연구 구매자는 위 이전 보상으로 선택권을 다시 배분한다.
5. `sourceProfileId + migrationVersion` 영수증과 새 profile을 한 번에 저장한다. 다시 열거나 버튼을 중복 눌러도 wallet을 다시 더하지 않는다. 이관 전후 수치를 사용자에게 보여준다.

이관 뒤에는 이전 버전의 추가 플레이·지출을 새 프로필에 반복 동기화하지 않는다. 두 경제를 서로 입금하는 통로를 만들지 않는다. 이관 구현·손상 저장 복구·동시 탭 검증을 통과하기 전에는 공개 기본 주소를 새 규칙으로 교체하지 않는다.

## 13. 계획 산술 검증의 범위

[계산기](design/reboot-planning-audit.mjs)와 [출력](design/reboot-planning-audit.json)은 세 기본 빌드의 투자량, 누적 XP, 조율권 총량, 반복 교체180전이, 수당 상한·예시·첫 연구 구매 여력을 확인한다. [도박 기대값 계산](design/reboot-risk-study.mjs)은 같은 데이터의 확률표를 사용한다.

이 계산은 실제 후보 생성·게임 플레이·20시드 완주·저장 원자성·모바일 성능·재도전 의욕을 검사한 것이 아니다. 해당 항목은 [검수 기준](REBOOT-UX-QA.md)에 남긴다. 도박 계산의1/2/4 가치는 실제 DPS나 모든 모듈 가치의 측정치가 아니다.

## 14. 변경 비용을 줄이는 구현 경계

| 책임 | 받아서 결정할 것 | 섞지 않을 것 |
| --- | --- | --- |
| 빌드/조립 | 장비·태그·분화·조율권 → 유효 결과/거래 | 화면 문구·렌더 프레임 |
| 후보 생성 | 장비·제외/제시 이력·분리 RNG·상자 타입 → 저장할 후보 | 저장소 직접 쓰기·현재 시각 추첨 |
| 전투/발동 | 고정 틱·공격 출처·태그·상태 → 피해/발동 사건 | 영구 wallet·연구 해금 |
| 진행/성과 | 고유 사건 ID·완료/사망·구역 → 단일 성과 원장 | 시각 효과가 끝나야 지급되는 숨은 조건 |
| 저장/계정 | revision·완성 거래·이관 영수증 → 확정/실패 | UI에 먼저 반영한 뒤 나중에 검증 |
| UI/표현 | 확정 상태·후보·예고 → 읽을 수 있는 화면/입력 | 별도 피해·확률·보상 공식 |

새 모듈은 호환 태그·발동 출처·강화 배열·상한을 한 정의로 추가한다. 같은 수치를 여러 화면에 복사하거나, 특정 무기 ID 예외를 쌓아 원래 규칙을 바꾸지 않는다. 이 경계는 새 프레임워크 도입 요구가 아니라 같은 규칙을 한 곳에서 판단하기 위한 개발 계약이다.
