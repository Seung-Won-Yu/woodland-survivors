# 대원별 특성·성장·빌드 설계

설계 0.8 · 2026-11-04 · **제안 규칙이며 현재 구현 완료 목록이 아니다.**

근거와 목적: [시스템 역분석](SYSTEM-REVERSE-ENGINEERING.md), [게임 기획](GAME-DESIGN.md). 캐릭터 선택을 ‘기본 능력치 하나 + 고유기 하나’에서 **성장 원천·행동·보상 선택이 달라지는 결정**으로 바꾼다. 여섯 대원의 이름·기존 원화와 고유기 이름은 유지한다.

## 1. 공통 구조

| 구분 | 규칙 |
| --- | --- |
| 기본 특성 | 출전 직후부터 행동을 다르게 만드는 능력. 특정 희귀 유물 없이도 작동 |
| 숙련 자원 | 대원마다 다른 실제 전투 사건으로 획득. 판 안에서만 유지 |
| 숙련 1 | 자원 1차 기준 + Lv.4. 정체성이 읽히는 작은 변화 |
| 숙련 2 | 자원 2차 기준 + Lv.10. A/B 중 하나 선택, 다른 분기는 같은 판에서 얻지 못함 |
| 숙련 3 | 자원 3차 기준 + Lv.18 + 첫 구역 보스 격파. 선택한 분기를 완성 |
| 고유기 | E/터치로 사용하는 큰 순간. 숙련 자원과 별도 충전 게이지 |
| 장비 자유 | 공용 시작 무기 유지. 추천 조합 외 선택도 플레이 가능해야 함 |

아래 HP·속도·수치 기준은 **첫 비교 실험값**이다. 원작의 수치가 아니다. 테스트 없이 정식 밸런스라고 부르지 않는다. 서로 다른 성장 사건을 같은 점수로 단순 환산하지도 않는다.

## 2. 한눈에 보는 분류

| 대원 | 역할 | HP / 이동 속도 | 고유 성장 자원 | 초기 기준 1 / 2 / 3 | 대표 완성 방향 |
| --- | --- | --- | --- | --- | --- |
| 다람쥐 | 관통·포격 | 100 / 192 | 다수 적중에 성공한 공격 횟수 | 30 / 100 / 220회 | 왕복 산탄·기류 |
| 토끼 | 기동·왕복 | 85 / 212 | 적이 가까운 전투 중 실제 이동 거리 | 400 / 1,400 / 3,200m | 왕복 산탄·회수 궤적 |
| 고슴도치 | 방어·반격 | 135 / 166 | 실제 방어와 가까운 위협 대응 점수 | 40 / 120 / 260점 | 보호 추적 벌떼·반격 |
| 여우 | 표식·집중 사냥 | 90 / 200 | 표식 처치 점수 | 5 / 14 / 28 | 집중 낙뢰·표적 폭발 |
| 두더지 | 지대·군집 제어 | 115 / 178 | 자신의 지대 안 무기 처치 | 20 / 70 / 160마리 | 만개 장미원·지대 연결 |
| 수달 | 회수·순환 | 100 / 192 | 실제 회수한 기본 XP 값 | 120 / 420 / 900 | 뇌우 연못·회수 파동 |

이동 거리의 화면 단위는 현재 `10 world units = 1m`에 맞춘다. 실제 이동 속도와 성장 시점이 맞는지 측정해 기준을 조정한다. 막힌 벽을 향해 입력한 시간은 이동이 아니다.

## 3. 다람쥐 · 흩어진 적을 한 줄의 화력으로

**플레이 문장:** 적을 모으고 관통할 각도를 만들어 공격 하나의 가치를 키운다.

| 항목 | 설계 |
| --- | --- |
| 기본 특성 | 공격 수 적용 무기 +1. 시작부터 산탄·낙뢰 대상·궤도 수 등 실제 적용을 표시 |
| 성장 판정 | 한 공격이 서로 다른 적 2마리 이상에게 실제 피해를 주면 숙련 +1. `castId`당 최대 1 |
| 숙련 1 | 관통/폭발이 없는 무기도 활용할 수 있는 짧은 보조탄 해금. 관통 성공 때만 발동, 간격 제한 |
| 숙련 2 A · 산개 | 발사 방향/대상 수 증가, 각 탄의 집중 화력은 낮아짐. 넓은 군집에 유리 |
| 숙련 2 B · 집중 | 산개 폭 감소, 같은 표적에 모인 공격의 효율 증가. 정예·보스에 유리 |
| 숙련 3 | A는 관통 후 분산되는 작은 탄, B는 제한된 집중 사격 창을 얻음. 두 효과를 함께 얻지 않음 |
| 고유기 · 집중 난사 | 조준 방향으로 짧게 집중 발사. 분기의 산개/집중 형태를 이어받음 |
| 추천 | 도토리·반달 / 공격 수·관통 / 바람 방울 |
| 대안 | 꿀벌·번개로 다수 표적 적중. 주력 무기 외 선택도 숙련을 쌓을 수 있음 |
| 약점 | 접근을 허용하면 버티기 어렵고, 넓게 퍼진 공격은 단일 표적 손실이 있음 |

검증: 같은 seed의 A/B가 군집 정리와 보스 시간에서 각각 설명 가능한 이득을 가져야 한다. 작은 적 하나를 계속 때려 숙련을 무한 생성할 수 없어야 한다.

## 4. 토끼 · 이동 경로가 공격 궤적이 되는 대원

**플레이 문장:** 무작정 도망치기보다 돌아오는 공격·경험치·다음 보상을 한 동선에 놓는다.

| 항목 | 설계 |
| --- | --- |
| 기본 특성 | 실제 이동을 이어 가면 공격 주기 개선. 정지하면 충전이 서서히 감소 |
| 성장 판정 | 살아 있는 적이 전투 범위에 있을 때 실제 이동한 거리. 벽 밀기·메뉴·빈 공간 왕복은 제외 |
| 숙련 1 | 이동 충전이 준비되면 다음 공격에 짧은 귀환 궤적 부여. 모든 투사체를 무한 귀환시키지 않음 |
| 숙련 2 A · 왕복 | 귀환 공격이 대원에게 도달할 때 다음 공격 준비에 이득. 동선을 공격과 겹침 |
| 숙련 2 B · 회피 | 위협 가까이를 벗어난 뒤 짧은 공격 강화 창. 실제 피격 직후 무적은 회피 성공으로 세지 않음 |
| 숙련 3 | A는 이동 경로를 가르는 왕복 연계, B는 회피 뒤 다음 발사의 명확한 강화 |
| 고유기 · 회피 질주 | 위험을 빠져나가고 지나온 길에 공격 기회를 남김. 단순 이동속도 숫자만 올리지 않음 |
| 추천 | 반달·도토리 / 공속·이동·투사체 속도 / 바람 방울·매듭 실타래 |
| 대안 | 이동하며 장판을 배치하는 반딧불 병 빌드 |
| 약점 | 낮은 HP, 정지 구간, 급한 궤적 변경 시 회수 공격 손실 |

검증: 이동 입력 시간 대신 실제 좌표 이동을 사용한다. 넓은 빈 공간에서 적 없이 도는 것이 최선의 성장법이 되어서는 안 된다.

## 5. 고슴도치 · 피해야 할 것과 막을 것을 구분

**플레이 문장:** 자리를 잡아 무리를 묶고, 막아낸 공격을 다음 반격의 기회로 바꾼다.

| 항목 | 설계 |
| --- | --- |
| 기본 특성 | 짧게 자리를 잡으면 전방 방어. 고유기만으로도 숙련을 얻을 수 있음 |
| 성장 판정 | 실제 방어/보호막 성공 + 방어 자세에서 가까운 위협을 처치한 점수. HP를 그냥 잃은 양은 자원이 아님 |
| 숙련 1 | 방어 성공 뒤 짧은 가시 반격. 발동 간격을 둠 |
| 숙련 2 A · 방벽 | 더 오래 진지를 유지하고 안전하게 회수. 공격 반격은 작음 |
| 숙련 2 B · 반격 | 보호막 소모 뒤 넓고 강한 반격. 재정비 중 방어 공백이 커짐 |
| 숙련 3 | A는 몸 주변 안전 구역, B는 방어 소모→귀환 공격의 공격적 순환 |
| 고유기 · 긴급 방벽 | 예고 공격에 맞춰 방어·반격 창을 제공. 누르는 즉시 모든 장판을 지워 주지 않음 |
| 추천 | 회전 가시·꿀벌 / 방어·범위 / 도토리 갑주·가시 매듭 |
| 대안 | 짧은 방어 창에 집중 사격하는 단일 표적 빌드 |
| 약점 | 느린 이동·회수, 원거리 적, 겹친 장판 안에서 계속 버티는 판단 |

성장 판정의 초기 계약:

- 실제 막은 값이 0보다 큰 유효 적 공격은 `clamp(막은 피해, 2, 12)`점. 같은 공격은 한 번만 집계한다.
- 방어 자세에서 150 world units 안의 적을 무기/고유기로 처치하면 2점. 잘 막기 전에 위협을 제거한 플레이도 인정한다.
- 정예 처치는 8점. 위 두 경로와 겹치면 동일 적 예산 안에서 합산한다.
- 일반 적 하나가 주는 누적 숙련은 최대 12점, 전체 획득은 초당 최대 12점이다. 보스는 서로 다른 예고 공격만 집계하고 최소 2초 간격을 둔다.
- 자기 피해·이미 무적인 프레임·유물의 재귀 추가 처치는 제외한다. 한 공격의 보호막과 방어를 중복 합산하지 않는다.

첫 구역의 기본 경로에서 희귀 유물 없이 보스 전 40/120점에 접근하는 사건 예산을 직접 측정한다. 원거리 안전 빌드는 숙련이 늦는 대신 받는 위험이 낮다는 대가를 갖되, 적 한 마리를 붙잡고 맞는 것이 최선의 성장법이 되면 실패다. 이 기준을 통과하지 못하면 수치만 낮추기보다 유효 위협 대응 판정을 수정한다.

## 6. 여우 · 많은 적보다 가치 있는 표적

**플레이 문장:** 군락 사이에서 표적을 먼저 잡아 다음 사냥의 힘을 얻는다.

| 항목 | 설계 |
| --- | --- |
| 기본 특성 | 전투 중 체력이 높은 적 하나에 눈에 보이는 사냥 표식. 정예·보스 상대로 장점 |
| 성장 판정 | 표식 대상 처치. 일반 1 / 정예 3 / 보스 6점. 일반 적도 기회가 있어 초반 숙련이 막히지 않음 |
| 숙련 1 | 표식 적중의 집중 공격 보너스 |
| 숙련 2 A · 추격 | 표식 대상에 닿는 공격·표식 전환이 빨라짐. 단일 사냥 연속성 |
| 숙련 2 B · 폭발 | 표식 처치 뒤 주변에 제한된 폭발. 군집 처리로 보상 전환 |
| 숙련 3 | A는 보스의 짧은 빈틈에 강한 사냥 창, B는 표식 폭발로 군락의 다음 표적 연결 |
| 고유기 · 잔상 미끼 | 표적과 일반 무리를 분리해 집중 사격할 위치를 만듦 |
| 추천 | 번개·추적벌 / 집중 피해·치명타 / 매듭 실타래·물결 조개 |
| 약점 | 표식 밖 화력과 회수 효율, 둘러싸인 상태 |

검증: 표식이 벽 밖이나 화면 밖 표적에 고정돼 진행을 막지 않게 한다. 사냥 점수는 실제 죽은 적에 한 번만 주고 분열·부활·자기 생성 효과를 악용할 수 없게 한다.

## 7. 두더지 · 적을 쫓지 않고 지대로 끌어오기

**플레이 문장:** 다음 싸움의 자리를 만들고, 들어온 무리를 모아 터뜨린다.

| 항목 | 설계 |
| --- | --- |
| 기본 특성 | 주기적으로 작은 발밑 지대 생성. 지대 무기를 안 골라도 숙련 시작 가능 |
| 성장 판정 | 자기 지대 안에서 무기/고유기로 처치한 실제 적. 유물 추가 처치는 재귀 성장에서 제외 |
| 숙련 1 | 지대의 체류 가치와 눈에 보이는 경계 강화 |
| 숙련 2 A · 진지 | 한 지대를 크게 유지. 강하지만 이동 시 손실 |
| 숙련 2 B · 연결 | 더 작은 지대를 둘 연결. 교대하며 적을 유도 |
| 숙련 3 | A는 모인 적을 정리하는 큰 파동, B는 두 지대 사이를 통과하는 연계 |
| 고유기 · 땅굴 탈출 | 현재 자리에서 탈출해 새 진지의 시작점을 만듦 |
| 추천 | 민들레·덩굴·반딧불 병 / 범위·지속 / 가시 매듭·생명씨 주머니 |
| 약점 | 빠르게 이동하는 보스, 급한 진지 포기, 범위 밖 원거리 적 |

검증: 효과 크기와 실제 지대 판정을 공유한다. 적을 붙잡아 판정을 계속 발생시키는 것이 반복 성장으로 계산되면 안 된다.

## 8. 수달 · 회수한 전리품을 다음 물결로

**플레이 문장:** 안전과 성장 사이를 오가며 회수의 순간을 공격 기회로 바꾼다.

| 항목 | 설계 |
| --- | --- |
| 기본 특성 | 회수 범위와 실제 회수 뒤 짧은 이득. 피해를 일부러 받아야만 성장하는 구조를 피함 |
| 성장 판정 | 실제 회수한 기본 XP 값. 자석에 끌리는 중이거나 아직 바닥에 있는 XP는 제외 |
| 숙련 1 | 모은 XP가 다음 공격 파동의 준비에 기여 |
| 숙련 2 A · 수확 | 회수와 이동을 돕는 큰 물결. 다음 성장 선택을 빨리 준비 |
| 숙련 2 B · 순환 | 회수·실제 회복을 짧은 전투 이득으로 교환. 발동 간격·상한 필요 |
| 숙련 3 | A는 넓은 회수/공격 순환, B는 회복과 밀침을 연결한 돌파 창 |
| 고유기 · 물결 회수 | 주변 전리품을 실제로 회수하며 길을 여는 파동. XP를 새로 생성하지 않음 |
| 추천 | 반딧불 병·번개 / 회수·지속 / 생명씨 주머니·물결 조개 |
| 약점 | 전리품 공급이 적은 단일 보스, 무리한 XP 회수 |

검증: 같은 XP를 바닥→비행→획득에서 중복 계산하지 않는다. XP 배율이 숙련 배율을 다시 증폭시키거나, 회복 유물이 만든 회복이 무한히 다음 회복·피해를 생성하지 않게 한다.

## 9. 구현 데이터 구조

아래는 개발용 설정 형식이다. 저장 스키마·상수 이름의 확정 API가 아니며, 구현 시 기존 모델과 검사를 함께 맞춘다.

```json
{
  "id": "pip",
  "role": "pierce",
  "base": {"hp": 100, "speed": 192},
  "mastery": {
    "event": "weapon_multi_hit_cast",
    "thresholds": [30, 100, 220],
    "levelGates": [4, 10, 18],
    "lastTierNeedsBossClear": true,
    "maxGainPerCast": 1,
    "branches": ["spread", "focus"]
  },
  "signature": {
    "id": "focused_volley",
    "maxCharge": 100,
    "startCharge": 25,
    "passivePerSecond": 0.5,
    "maxTotalGainPerSecond": 7
  }
}
```

runtime 저장에는 누적 자원·현재 tier·선택 branch·발동 간격만 넣는다. 객체·함수·무제한 사건 로그를 넣지 않는다. paused/choice/chest 등에서는 성장 시간이 흐르지 않는다. 이전 저장에 새 필드가 없을 때의 기본값과 손상 데이터 거절을 함께 정한다.

## 10. 화면에서 약속하고 검증할 것

출전 카드는 ‘역할 / 강해지는 행동 / 추천 조합 / 약점’ 네 줄로 비교한다. 실제 구현되지 않은 성장 규칙을 현재 게임 특성인 것처럼 표시하지 않는다.

전투에는 현재 대원의 숙련 하나만 표시한다. 예: `관통 숙련 18/30`, `기동 320/400m`, `방어 26/40`. 특성 설명·분기 상세·레시피는 일시정지에서 확인한다. 숙련 보상은 경험치 카드 사이에 묻지 않고 대원 이름과 분기가 보이는 별도 선택으로 알린다.

필수 검증:

1. 추천 무기와 다른 무기로도 고유 성장 시작이 가능한가?
2. 적·공격·XP 한 사건이 여러 프레임에서 중복 보상되지 않는가?
3. A/B 분기의 선택이 다른 행동·보상 우선순위를 만드는가?
4. 같은 seed에서 대원별 종료 무기 세트·주력 피해·위험 위치가 실제로 다른가?
5. 약점을 장비로 보완한 빌드와 장점을 극대화한 빌드가 각각 사용할 이유가 있는가?
6. 숫자와 게이지 없이 봐도 진화·Burst·최종 합체의 변화를 구분할 수 있는가?

첫 구현 비교는 다람쥐 A/B와 고슴도치 A/B 네 정책이다. 이 네 가지가 같은 선택·이동으로 수렴하면 나머지 대원을 같은 틀로 대량 구현하지 않는다.
