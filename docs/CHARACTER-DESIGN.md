# 대원별 성장·전투 설계 0.9

2026-11-05 · [원정 기획](GAME-DESIGN.md)의 대원 규칙 · **구현할 후보값, 원작 수치가 아님**

0.8의 ‘전투 점수 + 레벨 + 보스 격파로 숙련 3문턱’을 대체한다. 대원은 같은 XP 레벨을 다르게 활용하고, 고유 행동은 별도 필수 재화 대신 **고유기 충전과 실제 전투 효과**에 연결한다. 기존 이름·원화·고유기 이름·공용 시작 무기 선택은 유지한다.

## 1. 공통 성장 계약

| 시점/자원 | 규칙 | 화면 |
| --- | --- | --- |
| 출전 | 대원 기본 특성부터 작동. 추천 무기 외 공용 무기로도 시작 가능 | 역할·특성·약점·추천/대안 |
| XP 레벨 | 무기/보조에 투자하면서 대원 고유의 레벨 성장도 적용 | XP 게이지 하나 |
| Lv.6/12/18 | 대원 기본 특성 자동 보강 | 짧은 특성 알림, 메뉴 없음 |
| Lv.10 | 그 레벨의 성장 선택을 스타일 A/B 중 하나로 사용 | 대원 이름이 있는 선택 화면 한 번 |
| Lv.18 | 선택한 스타일의 완성 효과 자동 추가 | 기존 특성 알림/공격 변화 |
| E 충전 | 대원별 유효 사건 + 전투 중 완만한 기본 충전 | 고유기 게이지 하나 |
| 원정 종료 | 무기·레벨·스타일·E는 초기화. 발견/도전/기록은 보존 | 결과에서 다음 목표 하나 |

별도 점수를 모으느라 정상 레벨 성장이 막히지 않는다. Lv.18에서 기본 보강과 스타일 완성은 한 알림으로 묶는다. 레벨업이 여러 번 쌓여도 Lv.10 선택을 건너뛰거나 일반 강화와 별도로 이중 지급하지 않는다.

공통 E 후보값: 시작 25 / 최대 100 / 전투 중 기본 +0.5초당 / **모든 원천 합계가 임의의 1초 동안 최대 7**. 전투는 살아 있는 적이 유효 공격 범위 안에 있거나 그 적의 공격 경고가 활성화된 상태다. 빈 곳에서 메뉴를 열거나 벽을 미는 시간은 충전 사건이 아니다.

## 2. 다람쥐 Pip · 적을 모아 관통하고 화력을 배치한다

| 구분 | 설계 |
| --- | --- |
| 기초 | HP 100 / 속도 192 |
| 출전 특성 | 공격 수가 적용되는 무기 +1. 도토리·반달·꿀벌 등 적용 태그를 표시 |
| 자동 성장 | Lv.6/12/18에 관통 수가 적용되는 발사체의 관통 수 +1씩, 최대 +3. 관통 효과가 없는 장판을 관통탄처럼 취급하지 않음 |
| E 충전 | 한 무기 공격이 실제로 명중하면 +0.5, 같은 공격이 서로 다른 적 2명 이상에게 명중하면 추가 +2. 각 보상은 cast당 한 번 |
| 큰 행동 | E ‘집중 난사’: 조준 방향으로 짧은 관통 탄막. 스타일에 따라 산개/집중 형태가 달라짐 |
| 장점 | 적을 겹쳐 모을수록 같은 공격의 이득 증가, 빠른 군집 정리 |
| 약점 | 낮은 방어, 방향 밖 접근, 산개 시 단일 표적 손실 |

### 두 스타일

| 스타일 | Lv.10 | Lv.18 완성 | 유리한 상황 / 대가 |
| --- | --- | --- | --- |
| 산개 포격 | 적용 발사체 수 +2, 각도 확장, 탄당 피해 ×0.85 | 다중 명중 뒤 맞힌 위치에서 짧은 파편 부채꼴. 발동 간격 1.2초, 파편은 재귀 발동하지 않음 | 넓은 접근군/옆구리. 한 보스에 모이는 탄 수 감소 |
| 집중 포격 | 발사 각도 축소, 정예·보스에 무기 피해 +20% | 같은 정예/보스에 서로 다른 cast 3회 명중하면 1.2초 집중 창. 간격 4초 | 좁은 공격선/보스 빈틈. 주변 정리 범위가 작음 |

집중 스타일은 **적 하나만 남아도** 충전/완성 효과가 작동한다. 두 마리 적중 조건에 보스 효율을 묶었던 0.8 문제를 반복하지 않는다. 귀환탄이 같은 적을 다시 맞히거나 파편/유물 추가 공격이 적중해도 동일 cast의 충전 보상을 중복 지급하지 않는다.

추천은 도토리 + 반달 / 공격 수·공속 / 바람 방울이다. 대안은 꿀벌을 통한 표적 확보 또는 가시를 통한 접근 방어다. 추천은 획득 강제가 아니며 다람쥐가 보호 추적 벌떼를 만드는 것도 허용한다.

## 3. 고슴도치 Bram · 자리를 잡고 실제 위협을 받아낸다

| 구분 | 설계 |
| --- | --- |
| 기초 | HP 135 / 속도 166 / 기본 받는 피해 −2 |
| 출전 특성 | 0.55초 자리를 잡으면 전방 가드. 기본 용량 12, 재정비 2.6초. 이동 후 자세 유지 1.2초 |
| 자동 성장 | Lv.6/12/18에 가드 용량 +4씩, 최대 24. HP를 일부러 잃은 양을 성장으로 환산하지 않음 |
| E 충전 | 유효 가드가 실제 막은 피해 ×0.35. 방어 자세에서 150 world units 안의 적을 무기로 처치하면 +1, 정예는 +3 |
| 큰 행동 | E ‘긴급 방벽’: 2초간 전방위 방벽 용량 28 추가와 제한된 반격 창. 모든 적대 장판을 지우지 않음 |
| 장점 | 가까운 무리를 안정적으로 묶고, 막은 순간을 반격/회수 기회로 사용 |
| 약점 | 느린 이동, 측후면 공격, 겹치는 장판, 멀리 떨어진 사수 |

전방 가드는 표시되는 방향/범위와 실제 판정을 공유한다. 용량을 넘은 피해는 기본 방어 계산 후 HP에 들어온다. 자세를 만들었다고 무한 무적이 되지 않는다. E와 구르기/피격 무적의 우선순위를 명시하고, 이미 무적이라 받지 않았을 공격을 가드 성공으로 집계하지 않는다.

### 두 스타일

| 스타일 | Lv.10 | Lv.18 완성 | 유리한 상황 / 대가 |
| --- | --- | --- | --- |
| 굳건한 방벽 | 가드 용량 +8, 재정비 1.8초. 반격 피해는 작음 | 자세 유지 중 근처 적을 느리게 하는 보호 공간. 사격/장판 피해 자체를 삭제하지 않음 | XP 회수·근접 안정성. 보스 순간 화력이 낮음 |
| 가시 반격 | 가드 소진 시 넓은 가시 파열, 재정비 4초 | 소진 뒤 귀환 가시 출격. 간격 3초, 다시 E 충전/가드 파열을 만들지 않음 | 위험을 읽은 근접 폭발. 다음 가드까지 공백이 큼 |

방어 성공과 무기 근접 처치 양쪽을 인정하므로 특정 희귀 유물을 얻어야 캐릭터가 작동하지 않는다. 원거리 빌드를 선택해도 XP/레벨 특성은 정상 성장하며, 기본 전투 충전과 E로 능동적인 방어 기회를 만들 수 있다.

추천은 회전 가시 + 꿀벌 / 범위·공속 / 도토리 갑주 또는 가시 매듭이다. 갑주 유물의 보호막과 대원 가드가 같은 공격을 함께 막더라도 방어 기여/충전은 실제 막은 합계 한 번만 계산한다.

## 4. 충전·발동·기록의 경계

| 사건 | 허용 | 제외/제한 |
| --- | --- | --- |
| Pip 무기 cast | 서로 다른 실제 적 ID, 유효 피해 | 허공 발사·같은 대상 왕복 중복·지원탄의 재귀 충전 |
| Bram 방어 | 실제 적 공격의 예방된 피해 | 자기 피해·구르기/피격 무적·적 없는 자세 유지 |
| Bram 보스 대응 | 구별되는 예고 공격, 같은 공격당 한 번, 최소 2초 간격 | 한 장판의 매 프레임·동일 탄막의 모든 탄을 각각 보상 |
| Bram 일반 적 | 한 적에서 얻는 방어 충전은 생존 중 누적 상한 4 | 시간 경과로 같은 적의 상한이 초기화되는 파밍 |
| 근접 처치 | 일반 무기의 실제 처치 한 번 | 고유기·고유기 반격·특성 파열/귀환 가시·유물 연쇄·중복 사망 호출 |
| 메뉴 | 특성/재료/레시피 확인 | 전투 시간·충전·자동 발동 진행 |

cast ID·공격 주기·적별 상한 판정 등 0.8의 중복 방지 훅은 재사용한다. 무제한 사건 로그를 저장하지 않고 살아 있는 공격/적의 수명에 맞춰 정리한다. 도전 기록에는 다중 명중 횟수·실제 차단량 등 원래 사건을 남기며, E 충전 숫자를 실제 막은 피해로 보고하지 않는다.

## 5. 무기·유물과 함께 검증할 것

대원 스타일, 진화 핵심, 유물 연계의 적용 범위를 태그로 명시한다. 같은 이름의 효과를 세 층에서 자동으로 중복 지급하지 않는다. 예를 들어 ‘공격 수’는 궤도/산탄/추적의 적용 방식을 각각 정의하고, ‘관통 +1’은 전방위 파동에 보너스 숫자만 붙이지 않는다.

### 합체 후 적용표

| 합체 핵심 | Pip 공격 수·산개 추가 수 | Pip 관통 성장 | Pip 집중 정예/보스 피해 | Bram 방어·반격 |
| --- | --- | --- | --- | --- |
| 도토리 핵심 왕복 산탄 | 주 산탄 수에 한 번. 파편 수를 다시 늘리지 않음 | 주 산탄에 적용. 이미 무제한 관통이면 추가 효과 없음 | 일반 무기 명중에 한 번 | 대원 능력으로 유지. 특성이 만든 반격은 E 재충전 사건이 아님 |
| 반달 핵심 왕복 산탄 | 주 왕복 날개 수에 한 번. 귀환 때 재증가하지 않음 | 무제한 관통에는 추가 수치 효과 없음 | 출격/귀환의 유효 무기 피해에 적용. 동일 cast로 집중 창 횟수를 중복 집계하지 않음 | 같은 대원 방어 규칙 유지 |
| 가시 핵심 보호 벌떼 | 보호 궤도 수에 한 번. 출격벌 수에도 이중 적용하지 않음 | 유한 관통인 출격벌에만 적용, 궤도 접촉에는 미적용 | 궤도/출격벌의 유효 무기 피해에 한 번 | 유지. 합체의 귀환 파동은 무기 피해지만 반격이 만든 귀환 가시는 특성 피해로 구분 |
| 꿀벌 핵심 보호 벌떼 | 출격벌 수에 한 번. 보호 궤도 수에는 미적용 | 유한 관통인 출격벌에 적용 | 출격/귀환의 유효 무기 피해에 한 번 | 같은 대원 방어 규칙 유지 |

공격 수는 대원·스타일·보조의 증가량을 합산한 예산을 위의 주 채널 하나에만 적용한다. 초기 상한은 한 cast의 주 발사체 16, 보호 궤도 10이다. 산개 각도는 발사체에만 적용하고 궤도는 추가 수만 받는다. 파편·고유기·반격 가시는 자체 고정 수를 쓰며 공격 수 보너스를 다시 증폭하지 않는다.

집중의 +20%는 일반 무기 피해에만 적용한다. 고유기·특성·유물 피해에는 재적용하지 않는다. Bram은 어떤 합체를 들어도 자세/가드/반격을 유지하지만, 특성 반격·E 처치가 E를 충전하지 않는다. E 방벽이 **적 공격을 실제로 막은 사건**은 방어 충전으로 인정하되 같은 공격/적 상한과 초당 7 제한을 모두 적용한다.

합체 자체의 기본 산탄·폭발·왕복·벌떼·귀환 파동은 일반 무기 공격이다. 별도 대원 특성이나 유물이 추가로 만든 공격만 충전에서 제외한다. 따라서 합체 뒤 Bram의 정상 근접 무기 처치 충전이 사라지지 않는다.

| 비교 | 관찰할 차이 |
| --- | --- |
| Pip 산개 / 집중 | 넓은 군집 정리와 단일/이동 보스 처치가 서로 다른 방향으로 유리한가 |
| Bram 방벽 / 반격 | 실제 예방 피해·회수 여유와 반격 타이밍/처치 속도가 다른가 |
| 왕복 산탄의 도토리 / 반달 핵심 | 폭발 면적과 귀환 집중의 차이가 읽히는가 |
| 보호 벌떼의 가시 / 꿀벌 핵심 | 가까운 보호와 먼 위협 제거의 공백이 다른가 |
| 두 진화 유지 / 합체 | 단순 총 DPS 외에 공간·역할·빈 슬롯의 이득과 포기가 있는가 |

고정 비교는 넓게 흩어진 군집 / 좁은 길목 / 이동 보스 / 근접 포위에서 각각 수행한다. 정상 원정 모델과 고정 실험을 구분한다. 분기 하나가 두 seed에서 모든 상황을 지배하면 새 캐릭터를 추가하지 않고 해당 선택을 조정한다.

## 6. 나머지 대원

기존 토끼·여우·두더지·수달은 다시 잠그지 않는다. 기존 특성/고유기를 보존하되 0.8에서 제안한 별도 숙련 점수 체계를 새 규칙으로 일괄 구현하지 않는다. 기동·표적·지대·회수라는 역할 후보는 유지하고, 두 대원 검증 뒤 같은 공통 구조 안에서 성장/충전을 하나씩 정의한다.

## 7. 화면/수용 기준

- 출전에서 역할·자동 성장·E 충전 행동·약점을 짧게 비교할 수 있다.
- 첫 1분에 두 대원의 이동/공격 판단이 다르고, 희귀 유물 없이도 특성이 작동한다.
- Lv.10 스타일은 해당 레벨 선택 한 번, Lv.18은 알림 한 번이다. 무기 4단계 선택이 뒤따라 열리지 않는다.
- 단독 보스·파트너 미획득·촉매 지연·유물 없음에서도 성장과 고유기가 막히지 않는다.
- 합체 후 대원 스타일이 사라지거나 이름만 남지 않는다. 재료를 잃은 뒤에도 실제 현재 무기 태그로 판정한다.
