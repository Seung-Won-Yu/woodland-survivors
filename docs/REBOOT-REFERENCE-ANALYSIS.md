# 재기획 근거 — Megabonk와 Pokémon Survivor Burst

2026-11-06 · 공개 원문 확인 · [새 게임 설계](REBOOT-DESIGN.md)의 근거

## 조사 범위와 신뢰도

질문은 **같은 캐릭터로 다시 출격했을 때 무엇이 다른 성장·행동·위험 선택을 만드는가**다. 기능 수나 외형을 복제하는 조사가 아니다. Megabonk와 ClessioTV의 Pokémon Survivor Burst를 조사했다. PokéRogue와 브라우저 PokéSurvivor는 대상이 아니다.

이번에는 Steam 공식 소개·개발자 패치, Burst 공식 배포 페이지·개발자 변경 기록을 직접 열람했다. 원작 설치·장기 플레이·이용자 유지율 분석은 수행하지 않았다. 아래 ‘해석’은 설계 가설이며 인기의 인과를 입증한 결과가 아니다.

사용자가 제공했던 Megabonk PDF와 Burst 전체 페이지 이미지는 [0.9 판독 기록](REFERENCE-ANALYSIS-V09.md)을 재사용한다. Burst 캡처의 10.2.0과 현재 배포 페이지에 표시된 10.6.0을 혼합하지 않는다. 10.6.0 공지 링크는 확인했으나 본문을 가져오지 못했다. 따라서 ‘10.6 전체 규칙을 검증했다’고 주장하지 않는다.

## 2. 재미를 만드는 관계

다음은 위 사실에서 도출한 **우리의 해석**이다.

| 관계 | 플레이어가 하는 판단 | 보상만 추가하면 실패하는 이유 |
| --- | --- | --- |
| 캐릭터 특성 × 공격 방식 | 같은 아이템도 누가 들었을 때 더 잘 쓰는가 | 시작 총만 다르고 최종 빌드가 같으면 캐릭터 차이가 사라진다 |
| 초반 획득 × 투자 기회비용 | 나온 총을 키울지, 재료를 더 기다릴지 | 매번 파트너를 보장하면 발견이 조립 순서로 바뀐다 |
| 발동 효과 × 조건을 만드는 효과 | 도탄·연소·관통이 다른 효과의 기회를 얼마나 늘리는가 | 모든 보상이 피해 +N이면 이름만 다른 같은 빌드가 된다 |
| 희귀 보상 × 선택 통제권 | 현재 패를 쓸지, 바꿀지, 제외할지 | 필요한 재료가 안 나오면 손쓸 방법이 없는 판은 적응보다 재시작을 유도한다 |
| 탐색 보상 × 다른 교전 행동 | 지금 내 무장으로 저 위치·임무를 감당할 수 있는가 | 모든 거점이 경비 두 무리라면 동선만 길어진다 |
| 완성 화력 × 더 높은 위험 | 강해진 판으로 어디까지 이득을 가져갈 수 있는가 | 완성 직후 종료하거나 보스 HP만 늘리면 힘을 쓸 구간이 사라진다 |
| 결과 × 새 시도 | 이번 조합을 더 밀지, 다른 조합을 시험할지 | 수당 명세와 재출격 버튼만으로는 다음 목표가 구체화되지 않는다 |

## 3. 그대로 옮기지 않는 것

- **무기 합체를 두 작품의 공통 정답으로 취급하지 않는다.** 두 무기를 합치는 규칙은 우리 설계다. 단일 진화·발동 시너지 빌드도 같은 비용에서 경쟁해야 한다.
- 캐릭터·기술·맵·모드의 규모를 초기 제작량으로 복사하지 않는다. 적은 콘텐츠 안에서도 선택의 결과가 달라지는지 먼저 검증한다.
- 메가봉크의 3D 이동, 버스트의 포켓몬 타입·날씨 전체표를 탑다운 군사 전투에 그대로 붙이지 않는다.
- 원작의 전체 확률, 모든 성소/이벤트, 모든 캐릭터 공식을 안다고 전제하지 않는다. 특히 우리 도박 보급의 확률과 실패 대가는 아래 새 설계에서 독립적으로 정한다.
- 이용자 수·리뷰 점수에서 특정 시스템의 재미나 유지율 원인을 단정하지 않는다.

## 4. 현재 게임에서 폐기해야 할 오독

0.15.1 공개 수동 플레이는 [검증 기록](VALIDATION-V015.md)의 최종 순환 구간을 따른다. 기존 구현이 실제로 한 일과 새 기획의 의도를 분리한다.

| 현재 관찰 | 기획 실패 | 새 계약 |
| --- | --- | --- |
| 첫 보급에서 시작 총의 합체 파트너를 우선 보장 | ‘나온 패에 적응’ 대신 같은 조립 경로를 반복 | 서로 다른 초반 패 + 현재 총을 키울 안전한 선택 |
| 두 총의 3단 강화·고정 합체가 중심 | 완성 빌드가 소수 종착점에 수렴 | 공격 슬롯·조건부 모듈·분화의 교차 조합 |
| 거의 모든 성장 핵심이 선택 모달과 거점 경비 | 실제 이동·전투로 풀어야 할 문제가 비슷함 | 습격·엄호·돌파가 다른 행동과 보상 제공 |
| 합체 후 최종 보스가 약 7초에 종료 | 성장 체감은 있으나 완성 빌드의 시험이 짧음 | 완성 직후 대군, 짧은 공략 가능한 보스, 선택 잔류 |
| 귀환 1,611C → H 개조 두 개 연구 → 재출격 가능 | 기능적 순환은 성립하나 획득 경로와 목적이 다시 고정될 수 있음 | 연구는 후보 확장, 다음 목표는 미발견 상호작용·기록 |
