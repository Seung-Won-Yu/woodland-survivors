# 0.8 실험 보관 기록

2026-11-05 · 배포 보류 · 현재 기획 기준은 [GAME-DESIGN.md](GAME-DESIGN.md)

다람쥐·고슴도치의 행동 숙련, 무기 분기, 사냥 진척형 보스, 인장 진화·최종 합체를 연결한 로컬 실험이다. 원작의 규칙을 복원한 구현이나 새 기획의 완료판이 아니다. 공개 Pages는 0.6이다.

## 얻은 근거

- 둥지 없이 두 대원 × 두 분기 × 두 seed, 8회 일반 입력 모델에서 두 보스·숙련 III·진화·지정 합체를 완료했다. 외부 XP·능력치 지급은 하지 않았다.
- 해당 후보의 완주 시간은 266.1–322.9초, 합체 후 남은 플레이는 70.5–190.1초였다. `work/v08-model-final.json`에 원시 기록을 보관한다.
- HP 최저치는 **30초 표본** 기준이다. 다람쥐 산개/seed 73은 10까지 내려갔으며, 집중은 두 seed에서 산개보다 45–49초 빨랐다. 이 결과는 분기의 장단점이나 재미를 입증하지 않는다.
- 보관 기준선 `3a9ca4a`는 전체 130개 검사, 정적 빌드, Pages 경로 검사 3개를 통과했다. 이 검사는 새 기획의 구현 완료/게임성 검증이 아니다. desktop/mobile 전체 원정 흐름 검증은 남아 있다.
- 실제 모바일에서 고슴도치 출전·이동·피격·방어 숙련과 성장 선택을 확인했다. 고정 검수실에서는 숙련 선택·진화 공방 후보까지 확인했다. 일반 원정의 브라우저 완주 증거로 쓰지 않는다.

## 설계상 재사용하지 않을 연결

1. 320/2,800 사냥 수치로 보스 자격을 여는 구조와, 자격 획득 후 XP를 잘라내는 구조.
2. 대원 숙련과 무기 4단계 분기가 연속 모달로 나오는 구조.
3. 보스 보상 선택 → 공방 열기 → 진화/합체 → 계속하기로 분절된 보상 흐름.
4. 두 번째 이후 보스를 모두 `final`로 취급하면서 끝없이 계속하는 상태.
5. 매 성장 선택의 합체 파트너 강화 보장. 경로를 막지 않으려던 보정이 조합을 자동으로 완성시키는 방향으로 기울었다.

## 포팅 전에 해결할 구현 문제

- 첫 보스는 인장·보조 보상 외에 기존 캠페인의 유물 상자도 생성한다. 새 보상 계약과 중복되지 않게 분리한다.
- 다람쥐 집중 피해 창은 서로 다른 적 2명 적중이 필요해 단독 보스만 남으면 시작할 수 없다.
- XP 제한의 `xpBudget`과 `budgets[epoch]`가 따로 검증된다. 새 기획은 해당 제한 자체를 제거한다.

그림·이동/공격 포즈·적중/사망 반응·공간 충돌·보스 예고 판정·유물 연계·재료 소비의 원자성은 재사용 후보이다. 이 문서는 작업 보존 기록이며 배포 승인이나 게임성 검증 완료 선언이 아니다.
