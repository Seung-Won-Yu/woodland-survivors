# b04 — 보급의 역할과 화염 전투를 구분한다

2026-11-06 · 피오 독립 전투 시제품 · 구현 계약

현재 부족한 것은 완주 기능보다 선택의 결과다. 안전 상자와 두 습격이 같은 후보 풀로 돌아오고, 열압도 보통 폭발과 같은 모습이다. 이번 범위는 세 구역·연구 확장이 아니라 한 전장에서 얻는 패와 그 패의 전투 행동을 구분하는 것이다.

| 선택 | 포기/위험 | 성공 뒤 역할 |
| --- | --- | --- |
| 안전 확보 | 현재 공개된 상자를 확정 | 현재 모듈·강화 방향을 유지 |
| 보급차 습격 | 현재 상자 소실 가능, 탈출 전 HP900 격파 | 야전 개장 후보1: 미완성 L4+ 총 하나의 분화를 레벨 유지해 재선택. 대상 없으면 보유 총 강화1 후보. 나머지는 같은 품질 모듈 |
| 장갑 수송대 | 현재 상자 소실 가능, HP4200·전면 장갑·강한 호위 | 접근 가능한 미완성 진화/합체/열압에 기여하는 모듈1종을 확정 후보로 포함. 여러 경로면 공개된 규칙에서 추첨. 없는 총을 지급하거나 완성품을 강제로 만들지 않음 |

공격3·공용 모듈4, L4 분화, 조율권 비용, 무문턱 보스, 현재 상자만 잃는 실패 계약은 유지한다. 야전 개장도 보상3후보 중 하나를 선택하는 것이며 모듈과 동시에 받지 않는다. 초반 무료 개장·조율권은 소비하지 않고 총 레벨·사격 재사용 간격은 유지한다. 보급차/장갑의 보상 품질 확률은 기존70/27/3과40/45/15를 그대로 사용한다.

## 품질이 사라지지 않게 한다

- 희귀+2·원형+3은 강화량이 온전히 적용되는 모듈을 우선 제시한다. 미보유 모듈도 현재 무장과 호환되어야 한다.
- 필요한 기존 모듈의 상한을 넘는 강화는 명시적으로 전탄 보급 충전으로 전환한다. 남는1강화당20충전. 카드에 실제 강화와 전환량을 함께 표시한다.
- 유효 모듈이 부족하면 같은 품질의 의료/탄약/혼합 재보급 후보로 채운다. 품질별 의료12/24/36HP, 탄약25/50/75충전, 혼합8/16/24HP+12/24/36충전. 최대 HP·무기 레벨은 올리지 않는다.
- 원형품의 미보유 불안정 과급기는 첫 후보를 유지한다. 계약별 특별 후보와 중복되지 않도록 최대3장 안에서 조합한다.
- 재추첨2·제외1은 계속 공유한다. 재추첨해도 보상 품질과 계약 역할은 유지한다. 장갑 지원 후보를 제외하면 다른 유효 미완성 부품이 있는 경우 그 역할로 대체한다. 이미 보유한 지원 모듈은 해당 상자 자리만 교체하고 기존 투자·이후 XP 강화는 유지한다.

## 화염이 다른 행동을 만든다

촉매 보유 시 F는 아직 타지 않은 밀집군을 우선 점화하고, R과 H 유탄은 불붙은 유효 표적을 우선한다. 사거리·사선과 짧은 조준 유지는 지킨다. 가까운 적·부위·보스·수송차를 무시하고 화면 밖 연소 적만 쫓지 않는다.

열압은 별도 중심광·충격링·지면 불꽃으로 표현한다. 연소 전파의 연결과 열압 횟수를 전투 HUD에서도 확인한다. 일반 폭발·전기·열압은 시각과 소리로 구분하고, 줄이기 설정에서는 큰 플래시·흔들림을 줄인다. 지면 불꽃은 위험 경고를 가리지 않는다.

보급은 닫힘/교전/확보 상태의 외곽·경계등·상자 빛을 바꾸고, 습격 성공에는 기존 상자와 획득 품질을 연결해 보여준다. 화면을 멈춘 보상 선택으로 이어지며 임의 희귀도 재추첨을 만들지 않는다.

## 확인할 것

1. 같은 품질에서도 안전/보급차/장갑의 후보 역할이 실제로 다름.
2. 야전 개장의 레벨·모듈·조율권 유지, 잘못된 분화의 무변경 거절.
3. 보상 후보와 희귀도·계약이 저장/재추첨/제외 뒤 보존됨. 실패·철수에 성공 후보 미지급.
4. 모듈 상한 초과의 공개 충전, 모듈 전부 최대일 때 같은 품질 재보급.
5. 점화할 군집과 터뜨릴 연소 표적이 구분되고, 2차 피해의 무한 재귀가 없음.
6. 실제 인앱 브라우저에서 화염 연계 완성→보스→생존 귀환. 위험 보상은 별도 정상 입력 시도로 확인.

위 검사는 기능과 전달을 확인한다. 자유 플레이의 자발적 재출격과 장기 재미를 통과했다고 주장하지 않는다. 기존 공개 게임·저장·재화를 이관하지 않는다.
