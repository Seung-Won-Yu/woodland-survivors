## 군집 처리의 격리 검사

원정과 다른 통제 실험이다. 레벨·장비·무적·정지 표적·밀도 90·표적 보충을 사전 배치하고 생존이나 완주를 평가하지 않는다. 초기 공급 상한 1,200은 강한 무기들의 처리량을 가렸으므로 5,000으로 늘려 측정했다.

- 수호형 벌떼의 같은 표적 쏠림 수정 후 약 8.43→52.17처치/게임초. 보스 단독 DPS는 2,973→2,917로 비슷하게 유지됐다.
- 다람쥐 집중 8단계의 군집 속 보스 DPS는 175→1,226으로 회복됐다. 그 대신 잡몹 사냥보다 보스 집중에 힘을 쓴다.
- 도토리 핵심 왕복 산탄은 새 공급 상한 5,000에도 도달했다. 군집 위력이 이미 충분하므로 폭발 반경·배율을 추가 상향하지 않았다.
- 원정의 초당 처치나 사람이 느끼는 쾌감으로 이 수치를 일반화하지 않는다.

## 규칙·화면·입력 확인

[320px 실제 원정 화면](images/v010-mobile-320.png) · [합체 연출 검수 화면](images/v010-hive-mobile.png). 합체 캡처는 사전 장비·무적을 명시한 검수실이며 일반 원정 완주 증거로 사용하지 않는다.

- 게임 규칙·저장·유물·입력·전투 회귀 **154개 통과**, 정적 빌드 통과. Pages 하위 경로·배포 버전 검사 **4개도 통과**했다.
- 집중 조준·치유 꽃 선택, 무기만 받는 빈틈 보너스, 벌떼 표적 분산, 유한 재타격, 0.9/0.10 최고 기록 분리, 오디오 피격 우선순위를 검사한다.
- 320×700에서 HP 영역의 오른쪽 121px, 시계의 왼쪽 124px·오른쪽 196px, 지도 왼쪽 235px를 확인해 서로 겹치지 않음을 검증했다.
- 인앱 브라우저에서 일반 드래그·구르기 클릭·메뉴 전환 후 입력 해제를 확인했다. 사전 장비 검수실에서는 합체 완성 표시와 고유기 클릭 후 충전 100→0도 확인했다.
- 다중 터치 주입은 인앱 브라우저에서 지원되지 않는다. 두 손가락 소유권과 동시 행동은 포인터 회귀 검사로 확인했으며 실제 기기 두 손가락 플레이를 완료했다고 주장하지 않는다.
- 안전영역 CSS와 모션 감소 처리를 적용했다. 실제 노치 기기와 오디오 청감의 최종 평가는 추가 사람 플레이 범위다.

군락 진입 직후 미완성 고슴도치가 무너지던 경우는 첫 40초의 적 역할·공세를 완만하게 바꾼 뒤 두 진화 경로에서도 완주했다. 준비가 안 된 도전은 여전히 패배할 수 있다. 전체 무기·모든 대원·과밀 난이도의 균형을 동등하게 검증한 버전은 아니다.
